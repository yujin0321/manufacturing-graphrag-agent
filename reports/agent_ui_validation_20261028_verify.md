# Agent 대표 경로 검증 및 시연 화면 연결

2026-10-28. 기존 예원 v2와 검색 정책을 유지한 상태에서 통합 Agent의 문서 질문·복수 후보·현재 상태 경로를 실행하고 로컬 화면에 연결했다.

## 실제 실행 결과

| 사례 | 결과 | 실행 폴더 (`kg_build/graphrag_live/`) |
|---|---|---|
| MAINT-05의 정확히 25°C / 정확히 5분 | 최초 실행은 근거 전달 형식의 토큰 초과로 생성 전 중단 | agent_document_20261028 |
| 동일 문서 질문, 전달 형식 수정 후 | complete. 두 경계값 모두 미충족, >25°C가 >5분일 때 충족, SOP-003 원문 인용 | agent_document_fixed_20261028 |
| 특정 ID 없이 저장 후보 설명 요청 | needs_clarification. 전체 93건 중 10개와 후보 ID 선택 안내 | agent_multiple_20261028 |
| 현재 서버실 온도·냉각 실제 가동 여부 | insufficient_evidence. 현재 측정·실행 이력 부재 안내 | agent_current_20261028 |

문서 검색은 3,977토큰의 근거를 반환했으나 기존 Agent 전달 코드가 문자열을 JSON으로 다시 감싸며 추가 이스케이프를 발생시켰다. 근거 문자열을 원문 그대로 전달하고 실제 전달 텍스트로 예산을 검사하도록 수정했다. 원문·검색 순위·KG·4,000토큰 한도를 바꾸거나 청크를 잘라낸 수정은 아니다.

실패 기록을 보존하고 새 폴더에서 수정본을 검증했다. 도구 선택과 질문 임베딩은 최초 실행의 정확히 일치하는 요청 캐시를 재사용했고, 최종 답변만 새로 생성했다. 자동 재시도나 여러 답변 중 선택은 없었다. 수정 후 답변을 원문의 `TMP >25°C for >5 min`과 대조했다. 이는 개발 기능 검증이며 미노출 정확도 점수가 아니다.

## 이번 작업의 신규 API 사용량

| 호출 | 토큰 |
|---|---:|
| 문서 질문 선택 | 389 |
| 문서 질문 임베딩 | 64 |
| 복수 후보 선택 | 300 |
| 현재 상태 선택 | 289 |
| 수정 후 문서 답변 | 4,583 |

새 생성 4회 합계 **5,561토큰**, 새 임베딩 1회 **64토큰**. 수정 실행 기록에 있는 캐시 적중 선택 389토큰·임베딩 64토큰은 신규 사용량에 다시 더하지 않았다. 화면의 생성 사용량은 실행에 사용한 캐시 응답의 토큰도 포함하므로 이번 청구액과 동일한 개념이 아니다. 달러 청구액은 별도 결제 내역 확인이 필요하다.

## 화면 연결

- 기존 질문 영역에서 ‘기존 GraphRAG / Agent · 도구 자동 선택’을 선택할 수 있다.
- `/api/agent`는 기존 요청 출처 검사·동시 실행 제한을 적용한다. 실행 버튼을 눌렀을 때만 API 요청이 시작된다.
- 답변, 원문, 조회 관계, Agent 상태와 도구 실행 추적을 표시한다. 실패·선택 요청·근거 부족도 저장해 다시 열 수 있다.
- 저장된 결과 목록에 Agent 실행을 표시한다. ‘결과 열기’는 API 호출이 없다.
- 복수 후보의 선택은 ID를 복사해 새 질문으로 입력하는 방식이다. 대화 메모리나 선택 버튼은 아직 구현하지 않았다.
- 실제 로컬 브라우저에서 저장된 수정 후 문서 답변과 도구 실행 기록 표시를 확인했다. 화면에서 새 유료 실행을 반복하지 않았다.

검증에 사용한 주소: `http://127.0.0.1:8768/`. 기존 서버를 임의 종료하지 않고 새 포트에서 실행했다. 재시작은 기존 가상환경에서 `PYTHONPATH=src` 설정 후 `python -m imaks_kg.rag.demo --port 8768`을 사용한다.

## 테스트와 범위

Agent 계약·도구·모델 연결 테스트 21개 재통과. 화면 서버 테스트 6개 통과(Agent 요청 분기·타 출처 거부 및 기존 경로 회귀 포함). 실제 새 문서 질문은 임베딩→검색→답변 경로를 확인했고, 다른 두 경우는 실제 모델 분류 후 프로그램의 명확화·유보 처리를 확인했다.

후보 1건의 실제 설명 경로는 [이전 검증](../docs/AGENT_MODEL_CONNECTION_20261028.md)에 기록돼 있다. 이번 3개 질문과 합쳐 대표 기능을 확인했지만 모든 질문의 올바른 분류나 사실성을 보장하지 않는다. 독립 평가, 정답 이벤트 14건의 별도 시연 모드, 도메인 전문가 검증은 아직 남아 있다.

수정 파일: `src/imaks_kg/rag/agent.py`, `demo.py`, `demo.html`, `tests/test_agent.py`, `tests/test_rag_demo.py`. 기본 KG·추출 결과는 수정하지 않았다. 커밋·푸시는 하지 않았다. 보고서 저장은 사용량 제한에 따른 자동 승인 검토 실패로 한 차례 중단된 뒤 재개했으며, 재개 시 추가 API 실험을 하지 않았다.
