# 별도 CSV 재분석·시계열 API 검증 — 2026-11-15

완료 범위는 `예원12`의 백엔드다. 기존 v3.1 규칙 엔진을 재사용해 CSV별 분석·봉인·별도 KG 오버레이·원문 근거·페이지 단위 시계열을 제공한다. UI 화면과 새 자유 질문 Agent 연결은 추가하지 않았다. 유료 LLM·임베딩 호출 및 새 모델 설치는 0회다. main은 변경하지 않는다.

## 구현

1. CSV 7개 열, 센서/공정/구역/유형/단위, 유한 숫자, 30초 격자·중복 시각·행/크기 제한을 확인한다. 원본과 정규화 입력을 분석별로 보존한다.
2. 등록된 센서의 v3.1 실행 규칙을 적용한다. 기울기 기준은 기존 봉인 기준을 재사용하고, 분석 구간보다 미래인 기준이나 부족한 연속 창은 미평가로 표시한다. 업로드로 sigma를 학습하지 않는다.
3. 사건·관측 출처·KG URI를 분석 namespace에 연결한다. 실제 원문 관계와 실행/파일 참조를 구분한다. 같은 CSV를 두 번 넣어도 별도 분석으로 격리한다.
4. 차트에 원시 관측값·단위·기준선 출처·알람·사건 구간·관측 공백을 반환한다. 페이지 누락과 보간을 방지하도록 total/next_offset/표시 범위를 명시한다.
5. 사건 상세는 원시 관측·IR·원문·경로·사후 종료를 검사하고 코드로 일부 주장을 요약한다. LLM 생성 답변 또는 고장 원인 확정이 아니다.

## 검증

기존 Agent·XAI·탐지 엔진·오버레이와 새 입력/API를 포함한 **175개 회귀 검사 통과**. 새 검사 13개는 입력 오류, 누락/중복/비유한 값, 관측 공백, 미래 기준 차단, 원본 보존, 동일 입력 분리, 변조/경로 이탈 거부, 시계열 정확성과 페이지/구간, 무료 모드의 업로드·XAI와 유료 생성 거절을 확인한다. 기존 v3/v3-literal/v3.1 결과 동등성 검사도 통과했다.

처음 발견한 경로 거절 상태와 Windows 작업 스레드의 SHACL/SPARQL 파싱 문제를 보완한 뒤 전체 검사를 다시 통과했다. SHACL을 생략하거나 입력 해시 검사를 해제하지 않았다.

| 실제 로컬 API 사례 | 입력 | 탐지 | 검증 |
|---|---|---|---|
| 무작위 과거 구간 | 2026-01-07 20:32~22:32, 22센서, 5,302행 | 사건 0·알람 0 | 선택 센서 241개 시계열 값이 업로드와 정확히 일치 |
| 명시적 합성 이상 대조 | ST02 온도 90행, 알려진 조건을 만족하도록 만든 구간 | 사건 1·알람 4 | 새 CSV 출처·구조 근거·주장 게시 확인 |

무작위 구간은 seed 20261115로 정상 기준이 사용 가능한 공통 범위에서 선택했다. 기존 탐지 결과나 정답을 보고 다시 뽑지 않았다. 0건 결과를 그대로 유지하고, 양성 경로는 합성 대조라고 별도로 명시했다. 이 결과는 새로운 미노출 이상 탐지 성능·모델 답변 정확도·인과 발견을 의미하지 않는다.

기존 센서 입력, 기본 엔진 봉인, 고정 v2 KG의 해시가 API 실행 전후 일치했다. 업로드·시계열·사건 XAI는 API 키 없이 모델 생성 금지 상태에서 실행했다. 전체 원문/응답은 로컬 `kg_build/sensor_analysis_api_audit/`에 두고 [공유 집계](../docs/agent_handoff/sensor_analysis_api_audit.json)만 Git에 포함한다.

## UI 인계와 한계

실행·POST 예제·조회 필드·오류·샘플 생성은 [CSV·시계열 API 명세](../docs/agent_handoff/SENSOR_ANALYSIS_API.md)에 있다. 기존 별도 런타임 ZIP은 그대로 복원해 사용한다. 새 분석 결과는 각 PC에서 생성되며 기존 ZIP에 자동 추가되지 않는다.

- `--read-only --allow-local-analysis`로 로컬 CSV 저장/분석만 허용한다. 새 유료 답변은 계속 거절한다.
- `POST /api/analyses` → 분석 요약 → 센서 시계열 → 분석별 사건 XAI를 연결한다. UI 업로드 버튼/차트는 별도 구현이다.
- 사건 XAI는 코드 요약이며 일반 `/api/agent`로 업로드 데이터의 자유 질문을 처리하지 않는다.
- 시작/끝이 잘린 구간이며 관측 공백은 미확인 상태다. 후보 0건이나 규칙 해제를 실제 설비 정상·회복으로 표현하지 않는다.
- 고정 KG에 등록된 센서·단위·30초 격자의 UTF-8 CSV만 지원한다. 실시간 수집, 임의 센서 자동 등록, 분산 재학습, 다중 사용자 배포는 범위 밖이다.
