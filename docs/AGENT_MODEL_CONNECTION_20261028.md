## 동작

사용자 질문 → 모델의 JSON 경로 선택 → 코드의 도구·인자 검증 → 기존 도구 실행 → 근거 기반 한국어 답변 순서다. OpenAI native `tool_calls` 방식이 아니라 모델의 JSON 선택을 애플리케이션이 검사·실행하는 제한된 라우팅 방식이다. 자유로운 계획·반복 실행 Agent로 표현하지 않는다.

모델은 문서 질문, 후보 목록, 후보 설명, 현재 정보 부재, 명확화 필요 중 하나를 선택한다. 분류 자체는 모델의 판단이므로 오분류 가능성은 남는다. JSON 모드는 스키마 준수를 보장하지 않으므로 필드·도구·인자를 코드에서 추가 검증한다. 구현 근거: [OpenAI Docs의 구조화 출력 안내](https://developers.openai.com/api/docs/guides/structured-outputs).

- 문서 질문은 원래 사용자 질문으로 검색한다. 모델의 질문 재작성은 채택하지 않는다.
- 후보 설명은 사용자 질문에 실제로 명시된 ID 또는 전체 검색 결과가 유일한 후보만 허용한다.
- 여러 후보는 목록과 선택 요청을 반환한다. 후보 목록 요청도 추가 답변 생성 없이 결과를 표시한다.
- 유일 후보 발견 후 근거 조회는 코드가 연결한다. 모델의 추가 계획 호출을 줄여 현재 구현은 선택 1회, 최종 생성 최대 1회다.
- 현재 상태 질문으로 분류된 경우 확인 불가로 종료한다. 도구 실패·잘못된 JSON·불완전 응답·다른 모델 반환은 재시도하지 않는다.
- 근거는 최대 4,000토큰으로 제한하고 실제 최종 전송 형태를 다시 계산한다.

문서 검색 어댑터는 기존 질문 캐시를 먼저 사용하며, 없을 때 질문 임베딩을 최대 1회 호출한다. 모델 가중치나 문서 임베딩 전체를 다시 생성하지 않는다. 독립 도구 실행기 기본값은 여전히 캐시 전용이고, 통합 Agent에서만 API 어댑터를 주입한다.

## 실행

이 명령은 유료 API를 사용한다. 기존 `OPENAI_API_KEY`와 로컬 KG·문서·인덱스·탐지 자료가 필요하다. 새 실행 폴더를 사용해야 하며 완료 결과를 덮어쓰지 않는다.

```powershell
$env:PYTHONPATH='src'
$env:PYTHONUTF8='1'
..\.venv\Scripts\python.exe -m imaks_kg.rag.agent --question 'MAINT-05의 조건과 조치를 알려줘.' --run-dir kg_build/graphrag_agent_v1/my_new_run
```

실행 폴더에 입력·설정·코드/지침 해시, 모델 선택 원요청·원응답, 검증된 계획, 도구 추적, 최종 요청·응답·사용량을 저장한다. 키는 저장하지 않는다. `answer.json`의 `complete`는 실행 완료이며 사실성 자동 보증을 의미하지 않는다.
