GraphRAG 차이에는 키워드 검색 결합도 포함되므로 순수 간선 효과로 단정하지 않는다. 생성은 공통 실행 지침이 있는 도구 미사용 세션으로 수행했으며 팀원의 API 기반 Agent v4.1 전체 앱과 같은 구현이라고 표시하지 않는다. temperature·출력 토큰 상한을 직접 제어했다고 주장하지 않는다.

LLM 단독은 문서 미제공·판단 보류 허용 대조군이다. 모델 일반 지능 시험과 구분한다. 표준 산술·단위 변환과 질문에 주어진 가정은 추론 대상이고, 문서별 기준값·실시간 기록은 제공된 근거와 구분해 판단한다. 5점은 QA 지표이며 규칙 추출 F1_content와 다르다. 충실성 0점에는 전체 0점 처리된 거부·빈 답변도 있어 환각률로 뒤집어 해석하지 않는다.
