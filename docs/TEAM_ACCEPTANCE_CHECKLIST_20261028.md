## 역할 배정표

| 역할 | 담당자 | 완료 기록 |
|---|---|---|
| 자료 전달 및 버전 확인 | 미배정 | 날짜·전달 위치 |
| 다른 컴퓨터에서 실행 확인 | 미배정 | OS·Python·패키지·결과 |
| 평가 실행·로그 보존 | 미배정 | 조건 고정 확인·실행 ID |
| 정답/채점 관리 | 미배정 | 원문 근거·익명 응답 채점 |
| 결과 검토·실패 분석 | 미배정 | 이견·판정보류 사유 |

가능하면 실행 담당과 정답/채점 담당을 분리한다. 같은 사람이 담당해도 실제 역할과 정답 접근 이력을 기록한다. 팀원 이름이나 동의를 임의로 작성하지 않는다.

## 팀원 확인 항목

- [ ] 파일 크기와 `bundles.json`의 SHA-256이 일치한다.
- [ ] 일반 ZIP과 정답 시연 ZIP을 다른 폴더에 풀었다.
- [ ] 일반 안내에 따라 필요한 Python 패키지를 준비했다. API 키는 공유하지 않았다.
- [ ] 일반 서버를 열고 ‘저장된 결과’를 API 키 없이 확인했다.
- [ ] MAINT-05 경계 질문의 답변과 SOP-003 출처가 보인다.
- [ ] 여러 후보 요청의 선택 안내와 현재 상태 확인 불가 결과를 열 수 있다.
- [ ] Agent 실행 기록에서 실제 도구 이름과 상태를 확인했다.
- [ ] 원문·그래프 경로를 사실성 인증이나 원인 입증으로 해석하지 않는다.
- [ ] 정답 시연 HTML의 ‘정답 이벤트를 제공받은 시연’ 표시와 14개 항목을 확인했다.
- [ ] 정답 시연 자료를 일반 평가 검색 인덱스·KG에 추가하지 않았다.
- [ ] 발견한 오류를 기록했다. 해결되지 않은 필수 오류가 있으면 인수를 보류한다.

새 유료 질문은 인수의 필수 항목이 아니다. 실행이 필요하면 담당자의 API 계정·비용 범위를 확인한 후 별도로 기록한다. 저장 결과 확인만으로 새 API 권한이나 새 질문 정확도가 검증되는 것은 아니다.
