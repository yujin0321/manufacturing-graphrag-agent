## 공개 및 재현 범위

이 반영에는 코드·테스트·설명 문서·집계 보고서를 포함한다. API 키, 원문 작업 사본, 센서 데이터 작업 사본, 정답 라벨, 벡터 캐시, API 요청·응답 원본, 실행 후보 RDF/JSON 및 스크린샷은 로컬에 유지한다. 기존에 추적된 단계 6 자료는 그대로 둔다.

따라서 새 clone만으로 실제 실행이나 자료 의존 통합 테스트가 바로 가능한 것은 아니다. `PROJECT_HANDOFF_20261027.md`의 선행 자료가 필요하다. 보고서에 제시된 `kg_build/`와 `evaluation/` 경로 및 스크린샷 경로는 로컬 실행 증거 위치다. 모델 다운로드나 새로운 대용량 패키지 설치는 추가하지 않았다.

기존 보고서의 ‘아직 구현하지 않음’, ‘푸시하지 않음’은 작성 당시 기록이다. 최신 완료 범위와 공유 범위는 이 문서 및 통합 안내를 기준으로 확인한다.
