# 예원 v2 온톨로지 진단 — 실행 및 원인 분류

2026-10-27. 사전 고정한 진단 질문 8개를 기존 `live.answer`로 실행했다. 예원 v2 KG 2,806트리플, 모델 `gpt-6.1-sol`, 기존 검색 정책·생성 지침을 유지했다. 온톨로지와 KG는 변경하지 않았다.

## 결론

이번 질문에서는 **온톨로지 표현 부족 때문에 답하지 못한 사례가 확인되지 않았다.** 문서 질문 7개의 필수 근거 단위 8개가 모두 회수됐고, 현재 상태 질문 1개에는 확인 불가라는 적절한 내용이 생성됐다. 필수 답변 요소의 원문 대조에서 내용 불일치는 발견하지 못했다.

다만 **OD-08은 일본어로 답했다.** 이는 한국어로 답하라는 기존 system 지침 위반이다. 현재 상태의 확인 불가 판단은 적절했지만 전체 요청을 완전히 준수한 답변은 아니다. 온톨로지 수정의 필요성을 보여주는 오류로 분류하지 않는다.

‘8문항 모두 성공’, ‘정확도 100%’, ‘온톨로지에 문제가 없음’으로 확대하지 않는다. 익숙한 규칙을 활용한 소규모 개발 진단이며 AI 단독·비맹검 원문 대조다.

## 추가 관찰

### STUCK 정의의 범위

OD-05는 SOP-003 MAINT-03에 수치 허용오차가 없다는 점과, 별도 SOP-002 표6의 `std(last 10)<0.001×nominal` 기준을 구분했다. 표6이 실제 검색 컨텍스트에 포함됐고 해당 문장도 확인했다. 따라서 ‘IMAKS 문서 전체에 STUCK의 수치 기준이 없다’고 주장하면 안 된다.

기존 탐지기의 ‘정확히 같은 11개 값’은 구현 가정이다. 이번 답변 확인으로 탐지기를 수정하거나 과거 결과를 대체하지 않았다. 탐지기와 문서별 기준의 일치 여부는 별도 검증 과제로 남는다.

### 현재 상태 질문의 검색 관련성

OD-08에는 서버실 문서 근거 외에 창고 온도 KG 카드도 포함됐다. 답변은 이를 현재 서버실 관측으로 잘못 사용하지 않고 범위가 다르다고 명시했다. 불필요한 카드 포함은 검색 보완 관찰이며, 일본어 응답의 원인이라고 입증된 것은 아니다. 원인 확인을 위해 여러 답변을 재생성하지 않았다.

## 실행 통제

- 사전 질문·원문·KG·검색 정책·생성 지침·코드 해시 확인.
- 8개 독립 실행, 반환 모델 모두 `gpt-6.1-sol`. 완료 답변 재생성·선택 없음.
- 저장 API 요청의 system 메시지가 기존 지침과 같고, user 메시지가 질문과 해당 검색 컨텍스트만 포함하는지 전부 대조. 평가 판정표나 기대 근거 ID는 주입하지 않음.
- 사후 검토에서 답변·검색 결과·판정표·근거 청크의 해시 확인. 원래 판정표 변경 없음.
- 기존 기준선 699개 파일과 작업 사본 비교에서 차이 없음.

## 다음 단계의 판단

온톨로지 결함이 입증되지 않았으므로 바로 새로운 관계를 채택하지 않는다. 예원 v2는 계속 기준선으로 유지한다.

`requiresRuleCheck` 같은 직접 관계는 **구조 조회의 명확성·검증 가능성**을 비교하는 후보가 될 수 있다. 현재 텍스트 참조 방식도 두 질문을 해결했으므로 이를 ‘답변 불가 해결’ 실험이라고 부르지 않는다. 후속 실험은 별도 후보 그래프에서 방향성·원문 출처·조회 재현성·회귀를 비교하고, 효과가 없으면 채택하지 않는 방식이 적절하다.

한국어 출력 오류와 불필요한 검색 카드는 온톨로지와 별도 문제로 관리한다. 이번 단계는 현재 v2 실행과 원인 분류까지다. 프롬프트 수정·후보 온톨로지 구현·전후 재평가는 수행하지 않았다.
