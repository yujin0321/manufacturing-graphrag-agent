# 예원 v2 벤치마크 작성 결과

2026-10-23 사용자 요청에 따라 7차 질의응답 벤치마크 초안을 작성했다. 다른 팀원 검증 기능 통합과 Colab 문장 형식 민감도 검사는 이번 작업에서 진행하지 않았다.

- 30문항: 단일 규칙, 수치·조건, 연결·절차, 문서 비교, 근거·권한, 답변 한계 각 5개.
- dev 6개 / eval 24개. 운영용 분리이며 문서·규칙 수준 독립 홀드아웃이 아니다.
- 각 문항에 정답 요소 3개, 원문 근거·쪽·chunk·해시, 주요 오답 주의를 작성했다.
- 5점 QA 채점 기준과 3방식 × 30개 = 90행의 미채점 CSV를 준비했다.
- 담당1~5의 6문항씩 분담안을 작성했다. 실명과 최종 팀 채점 합의는 미확정이다.
- 질문 파일의 정답 필드 부재, 질문·정답 ID 일치, 유형·분할 수, 원문 인용 텍스트 해시, 채점표 행 수·열 수·문항/시스템 조합 중복 없음 확인.
- 정답과 작성 스크립트가 Git 제외 경로에 있는지 확인했다.
- 예원 v2 원래 candidate KG와 예측 SHA-256 불변. priority 추가 레이어·관계 확장본·다른 팀원 코드는 사용하지 않았다.
- 모델/API 호출, 새 모델 설치, RAG 구현·평가 실행, Git 커밋·푸시는 수행하지 않았다.

정답 권위는 v2 출력이 아니라 전처리 원문이다. 원본 PDF 시각 검수나 제조 도메인 전문가 승인은 하지 않았으므로 팀 검토 전 AI 작성 초안으로 명시했다. 평가 대상의 기존 정답 노출 이력도 유지한다. 이 QA 채점법은 제안안이며 기존 86개 규칙 추출 F1과 별개의 지표이다.

문항과 실행 방법: `docs/benchmark_yewon_v2_20261023/`. 정답과 채점표: `evaluation/benchmark_yewon_v2_20261023/`. 다음 단계는 팀원별 문항/원문 검토와 채점 기준 확정이며, 이후 설정을 고정해 세 시스템을 비교한다.
