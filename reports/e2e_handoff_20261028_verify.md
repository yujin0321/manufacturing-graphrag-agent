## 검증

Agent 계약·도구·모델 연결, 로컬 화면 서버, 기존 신규 질문, 후보 설명, 정답 시연 격리, GraphRAG 검색, 룰 탐지기 테스트 총 **50개 통과**. 실패·오류·건너뜀은 0개다. API는 가짜 응답 또는 기존 캐시를 사용했다. 로컬 로그는 `kg_build/e2e_handoff_20261028/tests.txt`, 기계 판독 요약은 `tests.json`에 보존했다.

`preserve_comparison_baseline.py verify --compare-working` 결과: 보존 ZIP 정상, 699개 파일 검사, 작업 사본 변경 목록 없음. 새 Agent·UI 코드는 별도 확장이며 기존 추출·비교 평가 기준선은 유지된다.

실제 모델 E2E 사례는 이전에 수행한 특정 후보 설명, 문서 경계 조건 질문, 복수 후보 명확화, 현재 상태 유보 기록을 활용했다. 이번 회귀 검증을 새로운 모델 정확도 점수로 보고하지 않는다. 정답 14건 시연은 원본 제공 상태의 그래프 조회이며 일반 QA·탐지 평가와 분리한다.

## 공유 범위

[팀 안내](../docs/TEAM_HANDOFF_20261028.md)와 `scripts/package_agent_handoff.py`의 명시적 파일 목록으로 일반 실행 묶음과 정답 시연 묶음을 나눈다. ZIP 내부 파일 해시·크기와 외부 ZIP 해시를 기록하며 API 키가 포함되면 생성 중단한다. 자동 업로드·Git 푸시는 하지 않는다.

일반 묶음은 코드·기존 v2·문서 청크·벡터·탐지 후보·대표 저장 결과를 포함한다. 가상환경·원본 전체 센서·전체 평가 데이터는 제외한다. 정답 묶음은 별도 정적 HTML로 조회 가능하다. 새로운 질문에 실제 모델을 실행하려면 팀원 환경의 API 키·계정 권한이 필요하다. Python 패키지 설치와 운영체제 차이까지 모든 팀원 장비에서 검증한 것은 아니다.
