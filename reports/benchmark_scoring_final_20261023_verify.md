# 벤치마크 2단계 채점 기준 확정

사용자의 명시적 위임에 따라 프로젝트 QA 채점 기준 v1을 확정했다. 실제 제조 전문가 경력·자격이나 전체 팀 동의를 주장하지 않는다.

기준은 내용 요소 3개 각 0/1점, 근거 단위 충족 비율 0~1점, 충실성 0/1점의 합계 5점이다. 주 지표는 eval 24문항 평균 QA 총점이며 완전 정답률·내용·근거·충실성·실행 실패율을 함께 보고한다. dev 6문항은 별도다.

단위 환산, 부등호, 시간·전제, 절차 순서, 문서 충돌, 인용 누락/허위, 실질적 기권, 실행 실패, 판정보류 처리와 소수 반올림을 명시했다. 일부 필수 내용 누락과 틀린 내용 단정을 구별한다. 근거 누락은 내용에서 중복 감점하지 않는다. 문서명만 제시하는 것과 유일한 규칙 ID를 정확히 제시하는 것도 구분했다.

확정 문서: `docs/benchmark_yewon_v2_20261023/채점기준_확정_v1.md`.

평가 담당자용 30문항 체크리스트와 8개 인위적 dev 채점 예시를 평가 폴더에 작성했다. 예시는 실제 모델 성능이 아니다. 90행 채점표는 모두 미채점이다.

질문·정답·원문·KG·채점 기준·체크리스트·예시의 해시를 `scoring_lock_v1.json`에 저장하고 manifest를 갱신했다. 모든 기록 해시를 재확인했으며 기존 질문·정답 내용·v2 KG 해시는 변경되지 않았다. 생성 스크립트는 동결 파일이 있으면 기존 버전 덮어쓰기를 거부하도록 했다.

현재 상태: 1단계 원문 검토 완료, 2단계 채점 기준 확정 완료. 3단계 Vector RAG 구현 및 4단계 dev 6문항 시험은 아직 진행하지 않았다. API 호출·모델 설치·평가 실행·Git 커밋/푸시 없음. 기존 규칙 추출 F1 86.19%는 별도 지표로 유지한다.
