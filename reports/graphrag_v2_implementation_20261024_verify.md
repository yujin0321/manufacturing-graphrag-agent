# 2번 GraphRAG 검색 개선판 구현 결과

2026-10-24 KST. 기존 기준선을 유지하며 별도 검색 코드 `src/imaks_kg/rag/graph_v2.py`와 정책 `docs/graphrag_v2/retrieval_policy.json`을 추가했다. 원래 예원 v2 KG와 기존 comparison.py/vector.py는 수정하지 않았다.

## 구현

- 한국어 조사에 붙은 문서·규칙 ID 인식 및 candidate 식별자의 규칙 별칭 처리.
- 전체 벡터 순위와 희소성 가중 어휘 순위를 RRF로 결합하고, 명시한 각 문서에서 최대2개 후보를 우선 확보.
- 규칙 노드의 출처를 그래프 카드 포함 여부와 독립적으로 원문 후보에 반영.
- 기존 그래프 구조와 원문에 명시된 관련 규칙 참조를 최대2홉 탐색. 문자열 참조는 검색용 연결로 구분하고 KG를 변경하지 않음.
- 원문 우선·그래프 카드 후순위로 합계4,000 기준 토큰 준수, 누락/선정 사유/전체 provenance 기록.
- 기존 질문 임베딩 캐시만 허용. 캐시 누락 시 명시적 오류로 중단하며 API 호출 없음. 답변 생성 기능은 이번 범위에서 추가하지 않음.

## 검증

합성 테스트 **7개 통과**: 한국어 조사 및 긴 ID 오인식 방지, 규칙 별칭·원문 우선, 복수 문서 포함, 관련 규칙 탐색과 KG 불변, 예산 초과 시 누락 보고, 결정적 순서, 캐시 미존재 시 네트워크 차단.

실제 KG와 저장 벡터를 이용한 합성 점검에서는 문서 SOP-001·SOP-002가 모두 포함됐고, 원문24청크·그래프3카드·합계3,456 기준 토큰이었다. 저장 벡터 하나를 합성 질문 벡터로 사용한 경로 검사이므로 자연어 검색 품질이나 정답 근거 회수율의 증거가 아니다.

`preserve_comparison_baseline.py verify --compare-working` 결과: 보존본699파일 SHA-256/ZIP 검증 통과, 기존 작업 파일 변경0. 새로운 코드/설정 파일만 별도 추가했다. API 호출0, 설치0, 답변 재생성0, Git 커밋/푸시 없음.
