전체 QA는 dev 16 + eval 80 = 96문항, 3방식 답변·채점 288개다. 변경되지 않은 77문항의 답변 231개를 보존하고 신규 19문항의 답변 57개만 추가했다. NEW-12는 제외했으며 시스템 오류 주입 2문항은 QA 점수와 별도로 다룬다.

## 진행 흐름과 비교 방법

문항 통합·중복 제거 → 원문·고정 KG 대조 → 정답 기준 검토 → 세 방식 답변 생성 → AI 채점 → 실패 분석.

- 공통 자료: 문서 7개·86청크, 고정 KG 2,806 triple.
- 두 RAG는 같은 문서·KG 사실 카드에 접근하며 최대 24항목·4,000토큰을 사용한다. 실제 입력량은 다르다.
- VectorRAG: 로컬 all-MiniLM-L6-v2 벡터 검색.
- GraphRAG: 같은 벡터 검색 + BM25 키워드 검색의 RRF 결합 + 기존 retrieval_v3 관계 탐색.
- 채점: 내용 3점 + 근거 1점 + 충실성 1점. 규칙 추출 F1_content와 다른 QA 지표다.
- LLM 단독은 외부 근거 미제공·판단 보류 허용 대조군이다.

## GraphRAG 평균이 높았던 범위

| eval 유형 | 문항 수 | VectorRAG /5 | GraphRAG /5 |
| --- | ---: | ---: | ---: |
| 문서·조건 추론 | 64 | 4.813 | 4.746 |
| KG 구조 조회 | 16 | 2.164 | 3.286 |

평균 차이는 주로 KG 구조 조회에서 나타났다. 신규 19문항에서 두 RAG는 모두 동점이었다. 완전 정답 수 역시 같아 모든 질문에서 우수하다고 결론 내리지 않는다. GraphRAG에는 BM25도 포함되므로 차이를 그래프만의 효과로 단정할 수 없다. 별도의 벡터+BM25 답변 조건은 이 결과 묶음에 포함하지 않았다. 유진 v5나 예원의 후속 구현을 적용한 실험도 아니다.

## 해석의 한계

AI 평가이며 독립 사람 교차 채점·제조 전문가 인증은 없다. 기존에 공유된 문항의 개발 재시험이고 단회 응답이므로 통계적 우월성·미노출 일반화를 주장하지 않는다. 기존과 신규 실행 날짜가 다르다. 달러 청구액과 엄격한 속도 비교는 확보하지 않았다. 별도 단일 사례의 구조화 조회 개선 점수는 본 결과에 합산하지 않았다.

기존 원격 브랜치의 규칙 추출 F1_content 82.35%는 별도 실험이며 위 QA 점수와 혼용하지 않는다. 1029 폴더의 확정 결과 14개는 바이트 그대로 보존해 게시했다. 과거 버전 백업과 미완료 실험은 이번 폴더에 포함하지 않았다.
