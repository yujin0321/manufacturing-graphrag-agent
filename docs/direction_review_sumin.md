## 구현 방침

1. 기존 전처리 입력만 사용하고 정답·seed KG를 추출 입력에서 배제한다. 전처리 문서 전체를 문서별로 묶어 청크 절단을 없앤다.
2. Role/Task/합성 Example, 고정 JSON schema, `gpt-6.1-sol`, Responses API, 단일 모델·fallback 없음. 문서별 요청과 원본 응답을 저장한다.
3. 출력 문장과 건수는 정답을 읽기 전에 고정한다. 출처 검증 실패는 기록하고 자동 점수에서 조용히 삭제하지 않는다. 검증된 규칙만 후보 KG에 넣는다.
4. 원문 수치·단위·조건·조치를 보존한다. SOP와 데이터시트의 충돌은 문서별로 유지한다. 목표 규칙 수에 맞추지 않는다.
5. 공통 평가 코어를 재사용하되 두 정의서 해시, 실제 모델, 처리 문서(0개 추출 문서 포함), 문장 형식 민감도와 실행 환경을 추가 기록한다.
6. 원본·고정 예측·매칭 목록은 로컬 전용. 공유 md에는 구현·집계·제한을 기록한다. 사람 검토를 AI 검토나 SHACL 통과로 대체하여 완료했다고 표기하지 않는다.

## 정답 노출 이력
