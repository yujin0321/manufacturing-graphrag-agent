# 선택 후보의 그래프 기반 설명

후속 검증: [유형별 검증 보고서](../reports/event_explanation_validation_20261026.md). 전체 후보 93건의 검색 준비 검사와 총 4개 대표 사례의 실제 답변 대조를 완료했다. 아래 단일 사례 기록은 최초 구현 검증을 보존한 것이다.

2026-10-26. 과거 탐지 후보를 선택하면 저장된 후보 그래프의 센서·실행 규칙·기존 KG 규칙·원문 청크 경로를 조회하고, GPT-6.1-Sol로 설명한다. 자유 질문용 GraphRAG v2와 별도의 **후보 ID 기반 그래프 검색 경로**다. 임베딩은 호출하지 않는다.

## 사용법

기존 가상환경에서 `PYTHONPATH=src`를 설정한 뒤 `python -m imaks_kg.rag.demo --port 8766`으로 실행한다.

1. 화면 아래 **탐지 후보와 원문 열기 · API 비용 없음**을 누른다.
2. 후보를 펼친 뒤 **이 후보 설명하기 · OpenAI API 사용**을 누른다.
3. 위 답변 영역에서 설명, 원문, 그래프 경로를 확인한다. 설명 실행은 선택 후보의 센서 값·조건·원문을 OpenAI API에 보내며 생성 비용이 발생한다.
4. 저장된 결과에서 같은 설명을 다시 열면 API 호출은 없다.

## 구현

- `src/imaks_kg/rag/event_explain.py`: 봉인된 탐지 산출물 검증 → 후보 ID 확인 → 별도 RDF 그래프 순회 → 원문 해시 검증 → 예산 내 컨텍스트 구성 → 답변 생성.
- `/api/explain-event`는 후보 ID만 사용한다. 클라이언트가 보내는 값·규칙은 채택하지 않는다. 기존 출처 검사와 동시 실행 제한을 적용한다.
- 검색 경로: 후보 → observedSensor / evaluatedRule → sourceChunk / existingRule. 임의로 인과 관계를 추론하거나 메타데이터 후보에 문서 근거를 붙이지 않는다.
- 기존 KG·질의응답 코드의 평가 기준선 699개 파일은 동일하다. 이벤트 그래프는 별도 산출물로 유지한다.
- 정답 라벨을 읽지 않는다. 실행은 `kg_build/graphrag_live/` 아래 별도 폴더에 입력·검색 경로·출처·코드 해시·프롬프트 해시·모델·원응답·사용량을 저장한다.
- 모델 변경이나 실패 시 자동 재시도하지 않는다. 새 임베딩이나 모델 설치는 없다.
- 기존 API 호출 형식을 재사용했다. `messages`, `store` 등의 형식은 [OpenAI Docs의 Chat Completions API](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)를 확인했다.

## 실제 검증 사례

실행: `kg_build/graphrag_live/event_20261026_maint05/`

| 항목 | 확인 결과 |
|---|---|
| 후보 | det-4220832c6ffd0c103c6e |
| 센서 / 규칙 | SRV01_SERVERROOM_TMP / MAINT-05 |
| 조건 시작 / 최초 판정 | 2026-01-07 12:00:00 / 12:05:30 |
| 최초 판정 값 | 26.9452°C |
| 조건 | 25°C 초과가 5분 초과 지속; 정확히 300초는 제외 |
| 원문 | SOP-003:p1:table1:chunk |
| 문서상 조치 | 보조 냉각 가동, 우선순위 CRITICAL |
| 검색 | 저장 경로 5개, 원문 1개, 컨텍스트 1,426토큰 |
| 실제 API | gpt-6.1-sol, 입력 1,716 + 출력 803 = 2,519토큰; 임베딩 0회 |

답변이 위 값·조건·출처를 일치하게 설명하고, 실제 고장·현재 상태·조치 완료를 단정하지 않는 것을 확인했다. 사후 종료 시각과 구간 통계도 최초 판정 시점의 정보와 구분했다. 브라우저에서 저장 결과 재열기와 원문·관계 표시를 확인했다.

자동 테스트: 후보 설명 3개(정확한 입력 전달/출처 경로, 메타데이터 후보의 문서 근거 부재, 잘못된 ID 차단), 시연 서버 5개 통과. 마지막 테스트에는 위조 ID 거부 및 클라이언트 값 무시를 포함한다.

이는 대표 1건의 기능 검증이다. 전체 후보 답변의 정확도나 새 미노출 평가 점수를 의미하지 않는다. 원문에 정의되지 않은 조건, 도메인 전문가 검증, 실제 설비 상태 확인은 해결하지 않았다. 이번 연결은 조건 일치 후보의 설명 기능이며 자동 제어나 확정 이상 판정이 아니다.
