# GraphRAG 로컬 시연 화면 검증

2026-10-24. 2번 시연 화면 구현 완료. `src/imaks_kg/rag/demo.py`의 로컬 HTTP 서버와 `demo.html`을 추가했다. 추가 패키지·모델 설치 없이 기존 live.answer를 연결한다.

## 구현

- 질문 입력, 4가지 유형 예시 입력 버튼, 명시적 유료 API 실행 버튼.
- 처리 중/완료/오류 상태와 중복 실행 차단. 예시 선택과 저장 결과 열람은 API를 호출하지 않는다.
- 답변의 표·강조·인용문 표시 및 검색 원문 펼쳐보기.
- 방문 노드, 그래프 카드 포함 여부, 출처 링크와 실제 탐색 관계 기록. 저장 관계와 텍스트 참조를 구분한다. 긴 경로는 접힘 및 내부 스크롤로 표시한다.
- 근거 부족·문서 충돌은 자동 판정한 것으로 표시하지 않고 한계와 원문 대조 안내를 제공한다. 미회수된 명시 문서가 있으면 표시한다.
- 127.0.0.1 전용 바인딩, Host/Origin 및 요청 토큰 확인, run ID 경로 제한. 키나 API 원시 기록을 브라우저 응답에 포함하지 않는다.

## 검증

HTTP 테스트3개 통과: 저장 응답·근거 표시와 무과금 조회, 다른 출처 요청/경로탈출 거부, 빈 질문 거부 및 유효 질문 함수 연결. 제한 환경의 소켓 권한 때문에 첫 실행이 실패했고 루프백 네트워크 권한으로 동일 테스트를 통과했다. 테스트 생성은 모의 함수이며 유료 호출하지 않았다.

실제 브라우저에서 저장된 MAINT-01 답변을 열고 표 렌더링·한계 안내·출처 목록·탐색 기록을 확인했다. 빈 질문 버튼 클릭은 요청을 보내지 않고 입력 안내를 표시했다.

이어 브라우저 예시 버튼과 실행 버튼으로 “SOP-003의 MAINT-01 조건과 조치는 무엇인가요?”를 실제 실행했다. 신규 질문 임베딩1회와 답변 생성1회, 생성 사용량3901토큰. 완료 표시, 결과 저장, 답변의 MAINT-01 조건·베어링 점검/윤활·HIGH와 SOP-003 표1 출처를 확인했다. 3386 기준 토큰 컨텍스트, 방문24노드·탐색310관계·입력 그래프카드4개가 화면에 반영됐다.

실제 기록: `kg_build/graphrag_live/ui_e07095c3b96b4dd7b6002277359b9f24/`. 화면 캡처: `kg_build/graphrag_live/demo_ui.png`. 로컬 전용이며 Git 제외 경로다.

이 검증은 UI 연결 확인이며 대표4유형 전체 시험이나 새 QA 평가가 아니다. 원문 표 전체의 규칙 문자열로 만들어진 참조 링크도 표시되므로 310관계를 독립적 의미관계310개로 주장하지 않는다. 기존 평가 기준선699파일의 무결성과 작업파일 차이0을 확인했다. 기존 KG·평가 코드는 그대로 유지했다. 이번 변경은 커밋·푸시하지 않았다.
