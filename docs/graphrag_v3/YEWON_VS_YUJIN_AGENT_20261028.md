## 실제로 드러난 개선 우선순위

1. **문서 규칙 적용과 실시간 조회를 분리하는 라우팅.** G09는 document/clarify/document,
   G10은 clarify/document/clarify, G11은 unavailable 3회다. 사용자가 준 값으로 규칙을 묻는 질문까지 거절한다.
2. **집계형 구조 질의.** G01은 CRITICAL 정비 규칙 전체 목록인데 일부만 회수했다. 엔티티 중심 탐색만으로 완전성을 보장하지 못한다.
3. **정의표 검색.** G14는 3회 모두 0점, G08은 정의 근거 누락으로 3회 모두 3.67점이다. dense 성능은 미측정이므로 켜면 해결된다고 단정하지 않는다.
4. **문서 답변과 후보 설명 지침 분리.** 현재는 기존 이벤트 설명 지침을 공유하여 문서 질문에도 후보 ID/최초 판정 정보를 덧붙인다.
5. **평가자 안정성.** 최초와 충실성 재검토 사이 15개 판정이 달랐다. 최초 입력에 실제 생성 컨텍스트가 없었던 한계를 발견해
   모든 완료 답변에 동일하게 컨텍스트를 추가하고 충실성만 재검토했다. 내용/근거/배점은 그대로다. 이 사후 절차와 최초 점수를 공개한다.
