# 평가 기준 합의 제안 (팀 공유용 요약)

원문: `docs/eval_definition_F1_content.md` (지훈 브랜치). 이 문서는 한 장 요약이다.

## 왜 필요한가
각자 만든 추출 결과의 점수를 나란히 놓고 비교하려면 **계산 방식이 같아야** 한다. 지금은 안마다 아래가 다를 수 있다.
- 유사도를 계산하는 문장 구성(`condition`과 `action`을 어떻게 합치는가)
- 비교 범위(문서 안에서만 비교하는가, 클래스까지 일치해야 하는가)
- 분모(정답 86건 전체인가, 처리한 문서의 정답만인가)
- 데이터시트 예측을 오탐으로 세는가
- 정답을 본 뒤 예측이나 프롬프트를 고쳤는가

계산법이 다르면 숫자만으로 우열을 가릴 수 없으므로, 같은 규칙으로 각자의 **고정된 예측 파일**을 다시 채점하자는 제안이다. 아래 값은 제안이며 합의되면 확정한다.

## 제안하는 계산 규칙
1. **유사도 문장:** `condition` + 공백 + `action` (ID, 인용문, 분류는 넣지 않음).
2. **임베딩:** `sentence-transformers/all-MiniLM-L6-v2` (revision `1110a243fdf4706b3f48f1d95db1a4f5529b4d41`), 정규화한 코사인 유사도. **0.6 이상이면 유효.**
3. **같은 문서 안에서만** 예측과 정답을 비교한다.
4. **일대일 할당(Hungarian):** 먼저 유효 매칭 수를 최대화하고, 같으면 **유효한 쌍의 유사도 합**을 최대화한다(무효한 쌍은 합에 넣지 않음).
5. **클래스는 매칭 제한에 넣지 않는다.** 매칭 뒤에 혼동표와 "분류까지 일치하는 F1"을 따로 본다(분류 오류가 놓침과 오탐으로 두 번 감점되는 것을 피하기 위해).
6. 분할된 예측을 **임의로 합치지 않는다.** 예측 건수 대비 정답 건수(세분화 비율)와 이론적 F1 상한을 함께 보고한다.
7. TP = 유효 매칭 수, FP = 매칭되지 않은 예측, FN = 매칭되지 않은 정답.

## 분모와 보고 범위
| 보고 | 예측 | 정답 |
|---|---|---|
| **주 보고** | SOP 문서 예측 전체 | **86건 전체** (미처리 문서의 정답은 FN) |
| 처리 범위 보고 | 처리한 문서의 예측 | 처리한 문서의 정답만 |
| 범위 밖 예측 | 데이터시트 예측 | 개수만 보고(주 점수에서 FP로 세지 않음) |

정답 86건의 문서별 분포(직접 확인): SOP-001 29, SOP-002 27, SOP-003 11, SOP-004 19, **데이터시트 0건**.

## 정답 노출 통제
- 예측 파일을 **고정(SHA-256)하고** 정의서 해시, 임베딩 모델 revision, 라이브러리 버전, 임계값을 `pre_evaluation_lock.json`에 기록한 **뒤에만** 정답 파일을 읽는다.
- 정답을 본 뒤 기존 예측의 문장·분류·건수를 바꾸지 않는다. 프롬프트를 고쳐 다시 돌리면 **새 실험**으로 표시하고, 첫 실행 점수를 기준선으로 남긴다.
- 정답을 본 적이 있는 이력은 보고서에 적는다(독립 시험이 아님을 밝힘).
- 모델이 둘 이상 섞였으면 모델별로 분리해 보고한다.

## 팀에 요청하는 합의 5건
1. 유사도 문장은 `condition + 공백 + action`으로 통일하는가?
2. 주 보고 분모는 정답 86건 전체, 데이터시트 예측은 범위 밖으로 분리하는가?
3. 클래스를 매칭에 넣지 않고 혼동표로 따로 보는가?
4. 임계값은 0.6 고정, 0.5/0.7은 민감도 보고만 하는가?
5. 각자의 고정 예측을 같은 정의로 재채점하고 `pre_evaluation_lock.json`을 공유하는가? (개별 정답 매칭 목록은 공유하지 않음)

## 재채점 방법 (지훈 브랜치 기준)
평가 코드는 `src/imaks_kg/eval/`에 있다. 예측 파일은 JSONL 한 줄에 규칙 하나이고 필수 필드는 `document_id`, `class`, `condition`, `action`이다(`identifier`, `sensors`, `model`은 선택).
```
python -m imaks_kg.eval --predictions <predictions.jsonl> --out-dir evaluation/<새 폴더> --meta <meta.json>
python -m imaks_kg.eval describe-gold      # 정답 구조만 출력(규칙 문장은 출력하지 않음)
```

## 확인하지 못한 것
- 각자의 점수는 재현하지 않았다.
- 위 규칙은 제안이며 팀 합의 전이다.
