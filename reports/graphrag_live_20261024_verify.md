# 새 질문 처리 연결 검증

2026-10-24. `src/imaks_kg/rag/live.py`에 새 질문 → 임베딩 → 기존 GraphRAG v2 검색 → 답변 생성 경로를 추가했다. 기존 평가용 코드·KG·설정은 변경하지 않았다.

## 검증

- 모의 테스트 3개 통과: 신규 임베딩 후 실제 검색 컨텍스트 전달/기존 실행 덮어쓰기 거부, 잘못된 질문의 API 호출 차단, 임베딩 실패 시 생성 중단 및 오류 메시지 비기록.
- 첫 테스트는 Windows 임시 디렉터리 쓰기 권한 때문에 실패했다. 저장소 내 테스트 임시 폴더로 변경한 후 3개 모두 통과했다.
- 실제 신규 질문: “SOP-003의 MAINT-01에서 진동 드리프트의 수치와 관찰 시간, 정비 조치 및 우선순위를 원문 근거와 함께 설명해 주세요.”
- `text-embedding-3-small` 신규 임베딩 1회(62토큰), `gpt-6.1-sol` 생성 1회(입력4087+출력413=4500토큰) 정상 완료.
- 3673 기준 토큰 검색 컨텍스트에 `SOP-003:p1:table1:chunk` 포함. 답변은 >0.05 mm/s over 60 min, 베어링 점검·윤활, HIGH를 해당 원문과 연결했다. 원문의 bearing과 KG의 main bearing을 구별하고 현재 조건 충족 여부는 확정하지 않았다.
- 저장된 신규 임베딩을 네트워크 호출 차단 상태에서 재사용하는 검사 통과. 기존 평가용 캐시는 읽기만 하고 신규 캐시는 별도 경로에 저장한다.
- 기준선699파일 검증 통과, 보존 대상 작업 파일 차이0.
