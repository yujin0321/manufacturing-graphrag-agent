# 담당 범위 마무리 결과

2026-11-14. UI 구현은 별도 팀원 담당이다. 이번 작업은 백엔드 응답 점검·설정 확정·사례 구성·인계 준비다.

## 1. 화면 대신 응답·근거 점검

기존 실제 실행 4개를 다시 생성하지 않고 점검했다. 화면 전달 답변·원문·간선이 저장 결과와 같은지, 원문 텍스트와 파일 해시가 고정 코퍼스와 일치하는지, 사건·관측·실행 매개변수가 봉인 결과와 같은지 검사했다. 그래프에 없는 간선이 응답에 들어가는지도 확인했다. 모두 통과했다.

사건 도구 이후 추가된 원문·유형 정의를 포함하면 최종 근거가 늘어나므로 `context_tokens`를 최종 XAI 근거 기준으로 바로잡았다. 별도 `tool_evidence_tokens`는 도구 단계 누적량이다. 기존 답변 원본은 수정하지 않았다. 실제 설정 API 호출에서 인자명 불일치를 발견해 수정하고, 실제 레지스트리 응답 검사를 추가했다.

저장된 AI 검토도 승인 상태였다. 이는 모든 자연어 문장에 대한 독립적인 전문가 판정이나 전체 정확도 검증을 뜻하지 않는다. 시각 점검은 이 작업에서 수행하지 않았다. [검사 결과](response_audit.json).

## 2. 기본값 확정

탐지기 `main_v3_1`, 문서 방식 `auto`다. CLI와 `/api/team-config`는 `team_runtime.DEFAULTS`를 공유한다. 다른 방식은 선택 기능으로 유지한다. 인계 시에는 `--read-only` 서버에서 시작해 비용 없이 저장 기록을 확인한다. 이 기본값은 비교 실험의 우승 선언이 아니다.
