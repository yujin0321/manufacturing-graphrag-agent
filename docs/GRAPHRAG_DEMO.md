저장소 루트 PowerShell에서 다음 명령을 실행하고 http://127.0.0.1:8765 를 연다. 기존 Python 환경과 로컬 인덱스/KG가 필요하며 추가 패키지나 모델 다운로드는 없다.

```powershell
$env:PYTHONPATH='src'
$env:PYTHONUTF8='1'
..\.venv\Scripts\python.exe -m imaks_kg.rag.demo
```

다른 포트는 `--port 8766`처럼 지정한다. 종료는 실행 터미널에서 Ctrl+C. 로컬 컴퓨터 전용이며 다른 사람에게 공유하는 공개 서버가 아니다.

## 사용

1. 질문을 입력하거나 예시를 선택한다. 예시 버튼은 입력만 한다.
2. **질문 실행 · API 사용**을 누르면 OpenAI에 질문/검색 문서를 전송하고 유료 임베딩·생성 처리를 한다. API 키는 서버 프로세스의 `OPENAI_API_KEY` 환경변수를 사용하며 브라우저에 전달하지 않는다.
3. 답변, 검색 원문, 방문 노드와 출처 링크, 실제 탐색 관계를 확인한다. 표·강조·인용문을 표시하지만 원문 HTML은 실행하지 않는다.
4. 저장된 결과 목록에서 **결과 열기**를 누르면 추가 API 호출 없이 재열람한다. 결과는 `kg_build/graphrag_live/ui_.../`에 저장한다.

처리 중 실행 버튼을 잠그고 서버에서도 동시 요청을 거부한다. 창을 닫거나 새로고침해도 이미 시작한 요청이 취소되는 것은 아니다. 오류 시 자동 재시도하지 않으며 실행 ID의 `failure.json`과 API 기록을 확인한다.

## 표시의 의미

- **답변:** 모델의 문서 기반 응답. 현재 설비의 실제 상태나 실행 결과가 아니다.
- **원문:** 검색 컨텍스트에 포함된 청크. 모든 청크가 답변에서 인용되거나 주장별로 검증됐다는 뜻은 아니다.
- **저장 관계:** KG에 저장되어 탐색된 관계.
- **문서 규칙 참조:** 원문/규칙 텍스트에서 찾아 탐색한 링크. 같은 표 청크에 여러 규칙이 등장해 생긴 링크도 포함된다. 명시적 인과관계나 신규 사실이 아니다.
- **방문 노드/프롬프트 카드:** 탐색 여부와 실제 그래프 카드 입력 여부를 구분한다. 방문 관계 전체가 모델 입력에 포함되거나 답변에 사용된 것은 아니다.
- **근거와 해석의 한계:** 정적 자료의 범위, 검색에서 빠진 명시 문서와 충돌 검토 안내. 근거 충분성/문서 충돌을 자동 판정하는 별도 탐지기는 구현하지 않았다.

기존 평가 기준선과 검색 코드는 변경하지 않는다. 이 화면의 시험은 인터페이스 검증이며 기존120/120 점수의 재평가가 아니다. 4가지 대표 유형 전체에 대한 시연 검증은 다음 단계다.
