작성일: 2026-11-06. 기준은 `main` 커밋 `6ce2c702a2b866500e03709e2e01ae2b63a6782e`다. 기존 `yewon_6th`의 KG·검색 실험을 다시 합치지 않는다. 이 변경은 `예원7` 브랜치에서만 관리한다.

## 반영 범위

| 항목 | 반영 방식 | 근거·한계 |
| --- | --- | --- |
| 같은 방향 연속 표본 확인 | `--warning-samples 2` 선택 옵션 | 확인 경고 50→39건, 라벨 사건과 겹치지 않는 경보 구간 1→0건. 일부 탐지가 지연되므로 기본값은 기존 1표본 유지 |
| 조기주의→확인 경고 이력 | `warning_transitions.json`에 `watch`/`confirmed` 별도 저장 | 첫 경계 초과를 즉시 보존. `watch_at`으로 동일 주의 구간의 승격을 연결 |
| 단계별 평가 | 센서·날짜 구간별 주의/확인/미확인 건수와 사건별 첫 알림 지연 | 미확인은 지속 조건 미충족이며 오경보와 동일한 뜻이 아님 |
| 지연 중앙값 계산 | `statistics.median` | 짝수 건수에서 중앙 두 지연의 평균으로 계산 |
| 회귀 검증·결과 공유 | 기존 탐지기 테스트 24개 + 소형 봉인 결과 묶음 | 같은 데이터의 개발 재시험이며 독립 테스트 성능을 주장하지 않음 |

문서 규칙과 위험 임계값의 탐지 결과는 원래대로 보존한다. 정상 범위 복귀, 상한↔하한 전환, 30초 간격 단절에서 경고의 연속 확인을 다시 시작한다. 정비 지시를 자동 실행하거나 통계 후보를 확정된 이상·원인으로 올리지 않는다.

## 기본 탐지기에 채택하지 않은 실험

추세/이동 σ/변화량 필터는 일부 DRIFT에서 빨랐지만 정상 구간의 검토 부담이 컸다. CUSUM은 조기 신호를 확보했으나 정상 라벨 시각 발행이 3,096건이었다. 운영 알림 정책으로의 적합성이 확인되지 않아 실행 코드와 연결을 이번 브랜치에 추가하지 않았다.

CUSUM의 관측 평균 복귀 표시는 합성 복귀 30회에서 모두 확인됐고 지연 중앙값은 8.75분이었다. 지속 변화 90회에서는 잘못된 표시가 없었다. 실제 자료에서는 755개 에피소드에 표시됐지만 실제 회복 시각 정답이 없고, 과거 표시 후 재이탈하는 사례도 있었다. **실험 결과로만 보존하고 자동 정상 판정이나 경고 해제에 연결하지 않는다.**

실험용 추세 스냅샷에 의존하는 과거 조회 Agent·자연어 연결도 이번 변경에 포함하지 않는다. 이 브랜치의 채택 범위는 탐지기와 평가다. 이전 실험 작업 파일은 로컬 작업본에 별도로 남는다.

## 실행

저장소 루트에서 기존 Python 환경을 사용한다. 새 모델과 API 키는 필요하지 않다.

```powershell
$env:PYTHONPATH='src'
$env:PYTHONUTF8='1'

# 저장된 소형 결과의 무결성과 점수 재계산: 원본 센서 파일 불필요
python scripts/verify_yewon7_detector.py

# main 전처리 산출물이 준비된 환경에서 실제 탐지 재실행
# 출력 폴더는 아직 존재하지 않는 이름을 사용한다.
python -m imaks_kg.detection.kg_rules --out kg_build/yewon7_watch2 --warning-samples 2
python scripts/evaluate_detector_events.py --run kg_build/yewon7_watch2

# 탐지기 회귀 테스트: KG/문서/센서 메타데이터 준비 필요
python -m unittest discover -s tests -p test_detector_kg.py
python -m unittest discover -s tests -p test_detector_rules.py
```

`kg_build`와 `evaluation`의 실행 결과는 기본적으로 Git에 올리지 않는다. 이번 검증에 사용한 비교 결과만 `artifacts/rule_detector_yewon7_20261106/`에 작은 묶음으로 보존했다. 그 안의 `evaluation/gold_events.json`은 재채점 전용이며 탐지 입력으로 사용하지 않는다. 센서 원본·환경변수·토큰 캐시·대형 모델은 묶음에 포함하지 않았다.
