# 주제·파이프라인 논의

논의일 2026-09-23 / 기록 정리일 2026-10-07.

- 팀 5인. 관심 기술: 온톨로지, 지식그래프, GraphRAG, AI Agent.
- iMAKS만 사용. 잠정 주제는 제조 공정 지식그래프와 GraphRAG 기반 설비 이상 분석 AI Agent.
- 실제 고장 원인 확정보다 근거 기반 점검 지원에 초점.

## 파이프라인

시계열 이상 탐지 → 센서·시점·스테이션 식별 → AnomalyEvent 추가 → KG·SOP 검색 → 점검 후보·근거·불확실성 안내.

GraphRAG가 원시 시계열의 이상을 직접 탐지하는 구조가 아니다. CSV는 규칙 기반 ETL, 문서는 온톨로지 제약 아래 LLM 후보 추출 후 검증하는 방향을 논의했다.

## 팀 기여 및 평가 방향

기존 KG를 그대로 적재하는 데 그치지 않고 온톨로지 설계·문서 추출·검증·동적 이벤트 추가를 기여로 삼는다. 일반 RAG와 GraphRAG의 근거 검색·답변 품질을 비교하고, 탐지 성능과 탐지 후 분석 성능을 분리한다. 정답 이벤트 입력과 탐지 이벤트 입력을 비교하는 평가도 제안했다.

독립 이상 이벤트 수가 적으므로 행 수를 독립 표본 수처럼 해석하지 않는다. 실제 공장 일반화·완제품 품질 판정·실제 고장 원인 확정은 주장하지 않는다. 세부 데이터 수치는 당시 전달받은 정보였고 10/5에 원본으로 확인했다.
