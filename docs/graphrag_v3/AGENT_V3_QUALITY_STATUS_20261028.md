# Agent v3 실제 품질 평가 실행 상태 (2026-10-28)

## 현재 상태: 모델 요청 권한 부족으로 미완료

- 평가 계획: 기존 고정 v3 15문항 x 3회 = 45개 실제 Agent 답변.
- 검색 설정: 현재 기본 BM25 + graph_v3, dense 없음.
- 평가 버전: agent-v3-quality-20261028-v1.
- 첫 G01 계획 요청이 HTTP 401로 거절되어 즉시 중단. 1건 시도, 생성 답변 0건. 나머지 44건은 호출하지 않았다.
- 생성 기록 및 중단 요약은 kg_build/agent_v3_quality_20261028_v1에 봉인했다.
- PRIVATE 정답은 읽지 않았다. QA 점수, 충실성, 실제 라우팅 정확도는 계산하지 않았다.

## 인증 진단

.env 키의 공백/따옴표/주석/환경변수 중복 문제는 발견되지 않았다.
모델 요청을 짧게 진단한 결과 서버 오류는 다음과 같다.

- HTTP 401
- code: missing_scope
- type: invalid_request_error
- Missing scopes: model.request

이는 모델 요청 권한 부족이다. 키가 단순히 만료됐거나 잘못됐다고 단정하지 않는다.
현재 키의 API 요청 권한과 조직/프로젝트 역할을 확인해야 한다. 비밀 키는 출력/보고서/Git에 기록하지 않았다.
읽기 전용 models 조회는 HTTP 403으로 거부되어 인증 유효성 판정에 사용하지 않았다.

## 재개

권한이 복구되면 새 출력 폴더에서 같은 고정 설정으로 평가를 실행한다.
실패 기록을 덮어쓰거나 최초 실패를 숨기지 않는다.

```powershell
$env:PYTHONPATH='src'
$env:PYTHONUTF8='1'
.\.venv\Scripts\python.exe scripts\evaluate_agent_v3_quality.py --out kg_build\agent_v3_quality_20261028_v2 --repeat 3
```

현재 실행기는 실제 답변 수집/봉인까지 구현했다. 완전한 답변 수집 이후 별도 채점 단계가 필요하다.
단위/통합 테스트 47개 통과 및 무료 실제 검색 성공은 유지되지만 실제 생성 QA 평가를 대체하지 않는다.

## 권한 저장 후 재확인

사용자가 Chat completions/Embeddings 권한을 저장한 뒤 v2~v4 새 실행 폴더에서 시도했다.
짧은 진단 요청과 Agent의 라우팅 요청은 실제 gpt-6.1-sol 응답에 성공했다.
그러나 G01의 최종 답변 요청은 다시 HTTP 401로 거절됐다. v3 최종 요청의 별도 진단은 missing_scope / model.request를 반환했다.
v4도 라우팅 후 최종 요청 실패로 즉시 중단했다. 완전한 QA 답변 수집은 여전히 0건이다.
원인은 권한 전파/키 또는 역할 설정 중 어느 것인지 확정하지 않았다. 추가 호출은 중단한다.

별도 채점 실행기 scripts/grade_agent_v3_quality.py를 준비했다. 불완전한 수집을 PRIVATE 정답 읽기 전에 거부하는 동작을 확인했다.
평가가 완료됐다고 표시하거나 일부 성공한 라우팅으로 답변 품질 점수를 만들지 않았다.
