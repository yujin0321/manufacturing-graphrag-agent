# 저장된 그래프 관계의 답변 기여: 오프라인 준비 결과

2026-10-28. 답변 생성 및 답변 채점은 아직 실행하지 않았다. API 호출 0회.

## 기존 비교에 대한 감사

기존 `graph_ablation_20261024` B/C는 저장된 RDF 관계 탐색, 원문 규칙 ID 참조 탐색, 노드의 출처 회수를 함께 비교했다. 따라서 기존 근거 회수 개선을 저장된 RDF 관계만의 효과로 해석할 수 없다. 특히 Q28의 개선 경로는 `text_reference_not_new_fact`였다.

기존 실행 파일 90개의 해시와 당시 코드·정책 해시를 확인했다. 예원 v2 KG를 그대로 사용하며 추가 관계나 정답 이벤트 시연 데이터를 투입하지 않았다.

## 이번 비교 정의

| 항목 | OFF | ON |
| --- | --- | --- |
| 저장된 관계 탐색 | 사용하지 않음 | appliesToSensor, actionTarget, hasSensor, feedsInto |
| 원문 규칙 참조 탐색 알고리즘 | 동일하게 사용 | 동일하게 사용 |
| KG 노드·식별자·출처 매핑 | 사용 | 사용 |
| 벡터·어휘 순위, ID 우선 검색 | 동일 | 동일 |
| 탐색 시작 노드 선정, 깊이·노드 상한 | 동일 | 동일 |
| 최종 원문 상한 | 24청크 / 4,000토큰 | 24청크 / 4,000토큰 |
| LLM에 제공하는 그래프 카드 | 없음 | 없음 |

OFF는 KG 전체를 제거한 시스템이 아니다. 측정 대상은 **원문 참조와 출처 매핑을 사용하는 현재 검색기에 저장된 네 종류의 관계 탐색을 추가했을 때의 증분 효과**다. ON에서 새로 방문한 노드의 원문 참조까지 도달하는 간접 효과와 탐색 상한 내 경쟁도 포함된다. 모든 종류의 그래프 효과를 일반화하는 실험은 아니다.

코드는 기존 `graph_v2.context`에 OFF일 때만 빈 `traverse_predicates`를 넘긴다. 두 조건의 공통 순위·우선 청크가 같은지 확인했고, ON의 최종 원문 컨텍스트가 기존 C와 일치함을 모든 문항에서 확인했다. 정답 파일은 준비 과정에서 읽지 않았다.

로컬 입력: `kg_build/stored_edge_ablation_20261028/`. 각 조건·문항에 `input.json`, `trace.json`이 있다. `audit.json`은 공통 조건 검증과 코드·입력 해시, `complete.json`은 결과 파일 해시를 기록한다. 재실행 시 기존 폴더를 덮어쓰지 않는다.

## 다음 답변 실험의 고정 절차

1. 기존 평가용 24문항 전체를 사용한다. 변경된 문항이나 Q28만 골라 평가하지 않는다. 개발 6문항은 별도이며 주 결과에 합산하지 않는다.
2. 동결된 OFF/ON 원문 컨텍스트를 사용한다. 기존 답변 생성 모델·시스템 지시문·최대 출력 길이·메시지 포맷을 동일하게 적용한다. 모델 응답의 실제 모델 ID도 기록한다. 기존 GraphRAG의 답변을 ON 답변으로 재사용하지 않는다.
3. 1회 비교는 24 × 2 = **48회 답변 생성**이다. 질문 임베딩은 이미 캐시에 있어 새 임베딩이 필요 없다. 동일 입력인 문항도 대조군으로 포함한다. 조건별 실행 순서를 교차하고 결과 캐시를 분리한다. 반복 실험을 한다면 반복 간 동일 응답 캐시를 재사용하지 않는다.
4. 답변 생성이 모두 끝난 뒤 정답과 팀의 기존 5점 기준을 적용한다. 내용 3점, 근거 1점, 충실성 1점 및 엄격 정답률을 각각 보고한다. 조건 이름을 가린 무작위 답변 ID로 채점하고, 채점 완료 후 조건을 연결한다. AI 채점이면 그 사실과 과거 정답 노출 이력도 명시한다.
5. 문항별 ON−OFF 차이, 개선·동률·악화 수, 평균 점수 차이와 엄격 정답 수 차이를 제시한다. 작은 차이는 1회 실행만으로 확정하지 않는다. 추가 반복은 비용 범위를 정한 뒤 별도로 실행한다. 가능하면 문항 단위 paired bootstrap 구간도 제공하되, 24문항의 불확실성과 반복 생성 변동을 구분한다.
6. 실패·미완료 응답과 사용 토큰도 공개한다. 근거 회수 변화 → 인용 변화 → 답변 변화 순으로 사례를 분석한다. 동일 컨텍스트에서의 점수 차이는 그래프 근거로 해석하지 않는다.

생성 지시문은 `docs/vector_rag_v1/answer_instructions.txt`, 모델 설정은 `docs/vector_rag_v1/config.json`, 채점은 `docs/benchmark_yewon_v2_20261023/채점기준_확정_v1.md`를 사용한다. 유료 실행 직전에 이 세 파일과 입력 봉인 해시를 다시 확인하고 실행 매니페스트에 기록한다.

이 24문항은 이미 본 **개발 재시험**이다. 새 대화나 조건 이름 가리기로 과거 노출이 없어지지는 않는다. 결과를 미노출 평가·도메인 전문가 검증·새 관계 발견의 정확도로 표현하지 않는다. 그래프 카드를 보여주는 효과는 이 실험에 포함하지 않으며, 필요하면 원문을 완전히 고정한 별도 비교로 다룬다.
