# LLM 단독·예원 v2 GraphRAG 비교 경로 구현 결과

2026-10-24 KST. `src/imaks_kg/rag/comparison.py`에 LLM 단독과 로컬 GraphRAG 실행 경로를 구현했다. 기존 Vector RAG 구현·설정·dev 응답·점수는 수정하지 않았다.

- 동일 생성 모델 gpt-6.1-sol, 공통 지시문, 출력 한도 4,096, 독립 요청, 실패 보존 정책을 적용했다.
- LLM은 검색 자료를 읽지 않고 빈 참고문서 필드와 질문만 전달한다.
- GraphRAG는 원래 예원 v2 2,806개 트리플을 읽으며, 문서 벡터 검색과 정확한 KG identifier 연결을 시작점으로 최대 2홉·24노드를 탐색한다. 그래프 최대 1,500 / 원문 포함 합계 최대 4,000 기준 토큰이다.
- 108개 KG 노드에서 문서 출처를 원문 청크에 연결했다. 이후 확장본·다른 팀 결과는 병합하지 않았다.

## 검증 결과

기존 12개와 새 6개 테스트, 총 **18개 통과**. 새 테스트는 LLM의 검색 차단과 공통 생성 설정, 실제 KG 무결성과 원문 연결, 합성 그래프의 2홉 경계, 식별자 완전 일치, GraphRAG 컨텍스트 전달과 불완전 응답 보존, 전체 청크 단위 예산 준수를 확인한다. 토큰 상한 보강 후 새 6개를 다시 실행해 통과했다.

실제 KG와 저장 벡터를 이용한 오프라인 기초 점검에서는 그래프 카드 2개와 원문 청크 8개, 합계 1,996 기준 토큰의 컨텍스트를 생성했다. 질의 벡터는 저장 벡터 하나를 재사용한 합성 점검이며 자연어 검색 성능이나 벤치마크 정답률 검증이 아니다. 네트워크를 금지하고 실행했다.

동결 평가 파일·원문·KG의 해시 8개는 모두 유지됐다. 실행 경로에는 정답·채점 파일 로더가 없다. 새 방식의 실제 생성 API 호출 **0회**, dev/eval 추가 실행 **0문항**, 패키지·대용량 모델 설치 **없음**. Git 커밋·푸시도 하지 않았다.
