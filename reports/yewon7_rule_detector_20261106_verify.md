# 예원7 룰 기반 탐지기 개선 반영·검증

작성일: 2026-11-06. `main`의 KG 기반 규칙 컴파일·실행을 바탕으로 검증에 도움이 된 변경만 골랐다. 반영 대상은 `예원7` 브랜치이며 main 수정·병합은 작업 범위에 없다.

## 채택한 변경

1. 첫 경계 초과의 조기주의(`watch`)를 남기고, 같은 쪽 경계를 연속 두 표본에서 넘으면 확인(`confirmed`)하는 옵션을 추가했다. 첫 초과 시각과 실제 확인 시각을 구분한다.
2. 주의·확인·미확인을 센서/시간 구간별로 집계하고, 라벨 사건 안에서 첫 주의와 첫 확인이 언제 발생했는지 평가한다.
3. 짝수 건수의 지연 중앙값 계산을 바로잡았다.
4. 테스트 및 비교 결과를 봉인된 소형 묶음으로 공유한다.

문서·위험 규칙은 기존 동작을 유지한다. 두 표본 확인에는 지연 비용이 있으므로 기본값은 한 표본이다. 두 표본 옵션을 사용할 때도 첫 주의를 숨기지 않는다.

## 재확인 결과

예측 두 묶음의 모든 파일 해시를 검사한 뒤 평가했다. 22개 센서 211,200행에서 얻은 기존 개발 결과이며, 원본 라벨 사건 14건은 새 미노출 시험 자료가 아니다.

| 지표 | 1표본 기준 | 조기주의+2표본 확인 |
| --- | ---: | ---: |
| 전체 탐지 구간 | 102 | 91 |
| 경고 구간 | 50 | 39 |
| 전체 사건 탐지 | 13/14 | 13/14 |
| 라벨 사건과 겹치지 않는 경보 구간 | 1 | 0 |
| 전체 최초 탐지 지연 중앙값 | 0.5분 | 0.5분 |
| 경고 계열 지연 중앙값 | 0.25분 | 1.25분 |
| ST02 전류 DRIFT 최초 탐지 지연 | 22분 | 40분 |

2표본 설정에서도 조기주의 50건이 보존된다. 39건이 확인되고 11건은 미확인이다. 문서 규칙 43구간과 위험 임계값 9구간은 ID·시각을 포함해 두 실행에서 일치했다. CORRELATED 사건은 여전히 미탐지다. 사건과 겹치는 알림이라고 해서 원인이나 정비 조치 효과가 입증되는 것은 아니다.

## 보류한 변경

추세·CUSUM 알림 정책과 그 결과에 의존하는 Agent 연결은 반영하지 않았다. 정상 구간의 알림 부담이 충분히 줄지 않았기 때문이다. 관측 평균 복귀 표시도 실제 회복 정답 없이 검증한 실험이므로 운영 정상 판정에 승격하지 않았다. 해당 실험의 성과와 한계는 사용 문서의 보류 항목에 요약했다. 기존 실험 작업 파일은 로컬에 보존했다.
