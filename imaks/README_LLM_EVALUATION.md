# LLM 답변 비교 실행

기존 검색 질문 14개에 일반 검색/그래프 검색의 근거를 각각 제공해 답변 28개를 비교합니다. 입력은 `assistant_outputs/llm_requests.jsonl`에 고정되어 있습니다.

## 현재 실행 방식

- 로그인된 Codex CLI의 `gpt-6-astra`, 추론 수준 low.
- 각 항목을 새 임시 세션에서 실행하고, 도구 사용이 발생하면 결과를 거부합니다.
- 원본 ZIP 전체가 아니라 질문·설비/센서 ID·상위 검색 근거 발췌문을 OpenAI Codex 서비스로 전송합니다.
- 준비한 시스템/사용자 메시지의 내용을 동일한 Codex 작업 프롬프트에 넣습니다. Codex 기본 지침이 남으므로 직접 API 호출의 역할 메시지 실험과 완전히 같지는 않습니다.
- CLI에서 temperature를 직접 설정하지 않습니다. 원래 계획의 temperature=0을 달성했다고 기록하지 않고 실제 값은 null, 제어 불가 사유를 저장합니다.
- 항목당 1회 생성이며 반복 실험에 따른 통계적 유의성은 주장하지 않습니다.

실제 외부 실행에는 해당 발췌문의 전송 승인이 필요합니다. 자동 승인 검토가 전송 대상·내용에 대한 구체적 승인을 요구했으므로, 사용자 승인 전에는 실행하지 않습니다.

## 실행·채점 코드

```powershell
.\.venv\Scripts\python.exe run_llm_evaluation.py --workers 3
.\.venv\Scripts\python.exe summarize_llm_evaluation.py
```

성공한 항목은 입력 해시가 같으면 재사용합니다. 실패한 항목을 가짜 응답으로 대체하지 않습니다. 생성 로그·모델 설정·토큰 사용량은 `llm_outputs`에 보존합니다. 파일의 모델 식별은 CLI 지정값이며 서비스 내부 모델 버전에 대한 독립 인증은 아닙니다.

## 평가 기준

`llm_rubric.json`은 생성 전에 고정한 질문별 필수 사실과 평가 기준입니다.

1. 자동 검사: 인용 ID가 실제 제공한 근거에 존재하는지, 필요한 근거를 얼마나 인용했는지.
2. 의미 평가: 근거 일치, 조건 처리, 질문 완전성을 각각 0–2점으로 검토.
3. 원문·실제 답변을 읽은 AI 검토 결과는 `assistant_review.json`에 근거와 함께 기록합니다. 사람 검토나 외부 독립 평가로 부르지 않습니다.

의미 평가가 없으면 빈 점수로 남깁니다. 인용 ID의 유효성만으로 환각 없음·조치 적합성을 판정하지 않습니다. 답변 해시가 바뀌면 기존 평가를 재사용하지 않습니다.

실행 방법 참고: [OpenAI 공식 비대화형 실행 문서](https://learn.chatgpt.com/docs/non-interactive-mode).
