# 비용 제한 평가 실행 안내

추가 API 호출과 다운로드를 하지 않는 전수 검색 평가 및 저장 답변 검토다.

- 전체 문항 코드: benchmark_catalog.py (130개)
- 검색 평가 대상: 102개. 입력 미지정 대기 26개와 별도 오류 주입 검증 2개는 검색 점수에 합산하지 않는다.
- 기존 API 임베딩 캐시: 35개 질문. 캐시 없는 67개는 API로 생성하지 않는다.
- 로컬 임베딩: PC에 저장된 jhgan/ko-sroberta-multitask 가중치로 전체 문항·동일 사실 코퍼스를 계산하고 저장한다.
- 기존 API 결과와 로컬 결과는 다른 모델이므로 별도 트랙으로 보고한다.
- 대표 답변: 6문항 × 3방식 = 저장 답변 18개를 원문과 대조한다. 새 생성·새 모델 채점 호출은 0회다.

## 재현 순서

원래 프로젝트의 Python 환경에서 offline_retrieval.py prepare, 로컬 모델 실행 환경에서 offline_local_encode.py, 다시 원래 환경에서 offline_retrieval.py retrieve 및 grade를 실행한다. 기존 결과를 덮어쓰지 않는 새 버전 폴더가 필요하다.
네트워크는 실행 코드에서 차단되며 로컬 모델은 local_files_only=True로만 읽는다.
