## 각 결과의 범위

- 예원은 문서 QA 24문항과 KG 관계·집합·경로 QA 12문항의 실제 답변 108개를 비교했다. 보고서에는 AI 채점 정정·보류 재검토가 기록돼 있다.
- 유진의 사건 16문항은 필수 근거 회수율을 측정한 오프라인 검색 실험이다. 텍스트 대조군은 BM25다. 생성 답변 정확도로 표현하지 않는다. 탐지 엔진·오버레이·Agent 도구를 함께 가져와 해당 실험의 코드 의존성을 보존했다.
- 성호의 원격 브랜치에는 10/30 QA 비교와 11/6 탐지 실험이 게시돼 있다. 별도로 공유된 11/9 main 통합 정정본과 실험 조건·수치가 다르다. 이번 통합은 위 원격 커밋의 게시물을 대상으로 했다.
- 수민 문서의 첫 비교는 예원 실행 결과의 재검토다. 이를 독립적인 추가 실행으로 중복 계산하지 않는다. 보강 실험은 그래프 조회를 끈 대조군·KG 확장·전체 문서 입력을 구분해 보고했다.
- 문서 QA, KG 조회, 사건 근거 검색, 사건 설명, 센서 이상 탐지는 서로 다른 평가다. 평가용 정답·과거 답변 기록은 새 생성 프롬프트와 검색 색인에 넣지 않는다.

## 코드와 재현

유진의 엔진은 `src/imaks_kg/detection/engine/`, 사건 도구는 `src/imaks_kg/rag/incident_tools.py`에 있다. 실행 명령과 입력 조건은 해당 문서를 따른다.

성호 실험은 독립 경로로 가져왔다. 성호 브랜치의 초기 프로젝트 구조·루트 설정·삭제 내역을 main에 덮어쓰지 않았다. 원본 실험의 바이트·공개 해시를 보존했다. 일부 재현은 실험에 포함된 ZIP의 입력과 실행 구조를 사용하므로 각 README를 먼저 읽는다.

모델 가중치·개인 API 키·로컬 가상환경을 추가하지 않았다. 새 유료 모델 실험은 실행하지 않았다. 이 통합은 위에 명시한 네 원격 브랜치의 게시 자료를 모은 작업이다.
