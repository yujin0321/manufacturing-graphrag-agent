# manufacturing-graphrag-agent
제조 공정 지식그래프(KG)와 Graph RAG 기반 설비 이상 분석 AI 에이전트

프로젝트 개요
• 목적: 제조 데이터셋을 기반으로 온톨로지 및 지식그래프를 구축(LLM 활용)하고, Graph RAG를 거쳐 설비 이상을 탐지 및 분류하는 AI Agent 구현.
• 핵심 기술: 지식그래프(Knowledge Graph), Graph RAG, AI Agent (LLM).

데이터셋 정보
• 출처: 2026년 공개 식품 포장 생산라인 합성 데이터셋 (온톨로지/KG 추출 및 Agentic Digital Twin 평가 목적).

• 구성 요소:

  • 생산 스테이션: 9개

  • 센서 및 시계열 데이터: 22개 센서, 데이터 211,200건

  • 이상 이벤트: 14개

  • 문서 자료: SOP 문서 4개, 센서 제조사 데이터시트 3개

  • 사전 구축 KG: Neo4j용 노드 115개, 엣지 341개

  • 평가용 데이터: 자연어 규칙에 대한 정답 트리플 86개

  • 추가 관계 정보: 유지보수 이벤트와 이상 해결 관계, 공정 간 영향 관계
  

프로젝트 주요 파이프라인
1. 데이터 확보 및 전처리: 제공된 합성 데이터셋(CSV, 텍스트 문서 등)의 정제 및 구조화.

2. 온톨로지 및 지식그래프(KG) 구축:

  • 설비-부품 구성, 공정 순서, 이상-원인-조치, 작업 매뉴얼 등 복합적 관계 정의.

  • LLM을 활용하여 텍스트 데이터(SOP, 데이터시트)에서 지식 추출 및 기존 KG와 통합.

3. Graph RAG 구현: 텍스트 문서(Vector)와 지식그래프(Graph)를 하이브리드로 검색하여 정확한 문맥 제공.

4. AI Agent 개발: 사용자의 질의나 실시간 센서 이상에 대응하여 RAG를 호출하고 조치 가이드를 제공하는 지능형 에이전트 완성.
