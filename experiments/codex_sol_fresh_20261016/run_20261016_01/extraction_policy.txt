Extraction policy v1 — fixed before full document reading/extraction.
Use only the six named input files. Read every document page/chunk/table document by document. No gold, prior predictions, evaluation or repository context.
Conversation-based AI extraction plus local deterministic serialization/validation; no API calls or keys. Requested model GPT-6.1 Sol; actual runtime model unverified unless trustworthy runtime metadata is available. Never invent usage/cost/time/request IDs.
Classify explicit normative operating requirements as OperationalRule; alarm thresholds and anomaly definitions as ThresholdRule; maintenance directives as MaintenanceRule; access/personnel/acknowledgement requirements as AccessRule, including source context. Datasheet descriptions/specifications are entity facts unless explicit condition/directive exists.
One source identifier remains one record even if composite; preserve compound condition/action without invented splits. Unnumbered explicit normative text gets a local document/page identifier. Threshold table: one row per sensor, preserve threshold labels in condition; no implied response. Definitions may have null action. Unconditional mandates may have null condition. Null is preferable to invented content. Preserve original English and operators/units/time. Do not turn diagnosis into a physical intervention.
Output fields: document_id, class, condition (string|null), action (string|null), identifier, sensors (array), equipment (array), action_targets (array), evidence (array), extraction_method, notes. Optional numeric thresholds/severity/priority only explicitly supported. Evidence: quote, document_id, page, chunk_id, table_id, row_index/col_index (1-based including header), bbox, char_start/char_end (0-based half-open in normalized page when applicable), text_sha256. Exact quotes from normalized supplied inputs. Table evidence uses cell coordinates and bbox; preserve raw/normalized distinction. Resolve abbreviations only using explicit same-document context or unambiguous supplied sensor inventory, record resolution method.
Retain immutable automatic original JSONL, then freeze hashes before filtering or AI review. Separate validation decisions and validated predictions. Source-based AI review is not human approval. Validation checks exact quotes, coordinates, hashes, allowed class, identifiers and entity links, not gold correctness. No target count/score.
KG: only source-validated rules and supported Station/Sensor/Document/Provenance and ontology-declared links; retain explicit provenance on entities/relations through sidecar evidence. Never add causal strength, lag, event instance or fabricated actions. Relations outside ontology or lacking required values remain separate candidates. SHACL inference none with supplied ontology. No claims that SHACL proves semantic completeness.
Freeze includes prompt, schema, policy, configuration, inputs, original predictions and extraction implementation SHA-256. Freeze file hash in separate checksum, no self-reference. Report score as 고정 후 별도 평가 대기. Original PDF hashes are manifest assertions only; binary PDFs are unavailable under input restrictions.
Exposure: project has historical gold exposure. This chat is input-separated, not an independent blind project test. Allowed ontology/shapes contain design/history references and aggregate counts/class alignment; these are schema exposure, never extraction targets. No linked files opened. Automatically supplied system/developer/environment instructions and delegation are visible; no upper repository instruction files read.
