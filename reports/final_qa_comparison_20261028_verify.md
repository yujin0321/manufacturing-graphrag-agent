# 예원 v2 기반 최종 QA 비교 정리

정리일: 2026-10-28. 평가 실행일: 2026-10-24. **저장된 결과를 종합한 보고서이며 새 평가·생성·재채점은 수행하지 않았다.**

## 핵심 결과

초기 비교에서 Vector RAG와 GraphRAG는 모두 106.5/120점이었다. 같은 예원 v2 KG를 유지한 검색 개선 이후 GraphRAG는 이미 본 24문항에서 120/120점을 얻었다. 이는 개발 개선의 관찰 결과이며 미노출 일반화 성능이나 순수 그래프 효과를 입증하지 않는다.

## 1. 평가 조건과 버전 구분

- 생성 모델: 세 방식 모두 기존 실행의 `gpt-6.1-sol`.
- 원문: 7개 문서·86청크. 기본 KG: 예원 v2 2,806트리플.
- 질문: dev 6개 / eval 24개. 주 비교는 eval 24개만 사용한다.
- 채점: 내용 요소 3개 각 0/1점 + 필수 근거 충족 비율 0~1점 + 충실성 0/1점, 문항당 총 5점.
- 공통 답변 지침과 출력 상한 4,096토큰을 유지했다. 각 문항은 독립 요청이다.
- LLM 단독은 질문만 받는다. Vector RAG는 코사인 top8 원문, GraphRAG는 원문과 KG 탐색 결과를 받는다. 최대 근거 예산은 4,000 기준 토큰이지만 실제 입력량은 다르다.
- ‘KG v2’는 기본 지식그래프 버전, ‘검색 개선 GraphRAG v2’는 검색 알고리즘 버전이다. 개선 때 KG를 교체한 것이 아니다.

초기 세 방식은 같은 비교 실행에서 수집했다. 검색 개선판은 그 결과의 실패를 분석한 뒤 별도로 실행했다. 개선판 비교에서 기존 LLM·Vector RAG는 재실행하지 않고 이전 결과를 유지했다. 네 행을 동시에 새로 실행한 결과로 표시하지 않는다.

## 2. 주 결과 — eval 24문항

| 시스템·실행 단계 | 총점 /120 | 평균 /5 | 완전 정답 | 내용 충족률 | 근거 충족률 | 충실성 비율 |
|---|---:|---:|---:|---:|---:|---:|
| LLM 단독 — 초기 비교 | 19 | 0.7917 | 0/24 (0%) | 16.67% | 0% | 29.17% |
| Vector RAG — 초기 비교 | 106.5 | 4.4375 | 18/24 (75%) | 87.50% | 85.42% | 95.83% |
| GraphRAG — 초기 비교 | 106.5 | 4.4375 | 18/24 (75%) | 87.50% | 85.42% | 95.83% |
| 검색 개선 GraphRAG v2 — 개발 재시험 | 120 | 5.0000 | 24/24 (100%) | 100% | 100% | 100% |

점수 개선은 +13.5/120점, 평균 +0.5625/5점, 완전 정답률 +25%p다. 처음 두 RAG의 총점 비율 88.75%와 완전 정답률 75%는 서로 다른 지표다.

초기 비교의 실행 실패는 세 방식 모두 0/24였고 판정보류는 없었다. 개선판의 완료 응답 24개도 정상 반환됐다. 개선판의 최초 제한 환경 연결 실패는 별도 보존된 기록이며, 완료 답변을 여러 번 생성해 선택한 것은 아니다.

LLM 단독의 낮은 점수에는 문서 접근 부재가 반영돼 있다. 충실성 점수가 낮은 답변 전체를 환각으로 해석하지 않는다. 기존 기준은 실질적 미답변에도 0점을 부여했으므로 무근거 단정과 기권은 개별 판정 사유로 구분해야 한다.

## 3. 실패와 개선 사례

초기 두 RAG는 다음 원문을 top8에서 놓쳤고 당시 그래프 탐색도 보충하지 못했다. 검색 개선은 문서·규칙 ID 처리, 문서별 근거 확보, 후보 수·순위 결합, 출처 탐색 및 카드 예산을 함께 변경했다.

| 문항 | 초기 GraphRAG → 개선판 | 관찰 |
|---|---|---|
| Q08 | 0 → 5 | SOP-003 정비 표1을 회수하여 MAINT-04 조건·조치를 답함 |
| Q09 | 2.5 → 5 | MAINT-05 보조 냉각과 >28°C PLC 종료 기준을 구분 |
| Q20 | 3.5 → 5 | SOP-001 자동 종료와 SOP-002 대응 절차의 출처를 구분 |
| Q25 | 2.5 → 5 | 역할 표와 hazmat 관련 제한을 함께 인용 |
| Q28 | 3.5 → 5 | CORRELATED의 90분 정의와 실측 시차·확률을 구분 |
| Q29 | 4.5 → 5 | 공정 표와 제품 데이터시트 양쪽 근거를 인용 |

개선판에서 점수가 내려간 문항은 없었다. 하지만 Q29의 ‘제공된 발췌에는 SOP 3개’라는 부연은 전체 코퍼스의 SOP 4개와 혼동할 여지가 있다. 만점은 문장 품질과 모든 표현이 완벽함을 뜻하지 않는다.

초기 GraphRAG Q10은 일본어로 답했지만 내용·부등호·인용이 맞아 기존 의미 기준상 5점이었다. 별도 언어 감점을 사후 추가하지 않고 한국어 지침 위반으로 기록했다. 개선판은 한국어로 답했으며, 이후 별도 8문항 진단에서도 다른 일본어 응답이 관찰됐으므로 언어 준수 문제가 완전히 해결됐다고 주장하지 않는다.

## 4. 생성 토큰과 속도

| eval 24문항 | 입력 토큰 | 출력 토큰 | 합계 |
|---|---:|---:|---:|
| LLM 단독 | 6,821 | 5,159 | 11,980 |
| Vector RAG | 29,596 | 7,206 | 36,802 |
| 초기 GraphRAG | 62,990 | 7,844 | 70,834 |
| 검색 개선 GraphRAG v2 | 98,164 | 8,491 | 106,655 |

개선판은 더 많은 생성 토큰을 사용했다. 이는 생성 요청의 토큰 합계이며 초기 인덱스 구축·질문 임베딩·Agent 분류 비용을 모두 포함한 총비용이 아니다. 실제 달러 청구액과 비용 우위는 확정하지 않는다.

초기 실행은 문항 병렬 처리와 캐시 공유가 있었고 개선판은 별도 실행이었다. 동일한 직렬·네트워크·캐시 조건의 응답 시간 비교가 아니므로 이 보고서에서는 속도 순위나 지연 개선을 제시하지 않는다. 새 공정 비교가 필요하면 사전 계획에 따라 별도로 측정해야 한다.

## 5. 해석의 한계

1. 과거 정답 노출, 익숙한 문서와 질문, 실패를 본 뒤의 개선이 있다. 요청에 정답표를 넣지 않았다는 사실이 개발 과정의 노출을 없애지는 않는다.
2. 구현·결과를 아는 AI의 단독·비맹검 채점이다. 독립 제조 전문가나 독립 인간 검토로 표현하지 않는다.
3. 같은 24문항의 단회 응답이며 근거도 중복된다. 통계적 우월성·새 질문 일반화는 검증하지 않았다.
4. 검색 변경이 여러 개 함께 적용됐다. 앞선 검색 비교의 필수 근거 34/35→35/35 결과는 검색만의 관찰이며 답변 성능의 순수 그래프 기여를 분리하지 않는다.
5. 정답 이벤트 14건 시연, Agent 경로 테스트, 추출 F1_content 86.19%, 센서 탐지 F1은 이 QA 점수와 별개다. 서로 합산하거나 대체하지 않는다.

## 6. 프로젝트에 적용할 결론

예원 v2를 공통 지식 저장 구조로 유지하면서 문서·규칙·센서·출처 연결을 활용한 QA 시스템을 구축했다. 초기 구현에서는 Vector RAG와 GraphRAG가 같은 점수였고, 실패 분석 후 검색을 보완한 개발 재시험에서 GraphRAG 점수가 상승했다. 이는 현재 자료의 근거 회수와 답변 보완 사례로 제시할 수 있다.

발표 권장 문구:

> 동일한 예원 v2 KG를 유지한 채 검색을 개선한 개발 재시험에서, 기존 24문항 QA 총점이 106.5/120에서 120/120으로 상승했다. AI 단독 채점이며 이미 본 문항의 결과이므로 미노출 성능과 그래프 고유 효과는 별도 검증이 필요하다.

추가 유료 실험 없이 이 결과와 한계를 최종 보고에 사용할 수 있다. 팀원 환경 인수와 팀 단위 결과 검토는 아직 별도 확인이 필요하다.
