# 벤치마크 1단계 원문 대조 결과

사용자 위임에 따라 30문항을 재검토하고 질문·정답·채점 해석을 수정했다. **그대로 통과 16개, 수정 후 통과 14개, 보류 0개**다. 최종 30문항(dev 6/eval 24)은 유지했다. 이는 내용·문항 원문 검토 완료이며, 2단계 채점 기준 확정이나 시스템 성능 평가 완료를 뜻하지 않는다.

## 검토 방법

로컬 `iMAKS_dataset.zip` 안의 SOP 4개·데이터시트 3개 PDF 바이트를 문서 manifest SHA-256과 대조했다. 원본 PDF 10쪽을 기존 번들 PDFium으로 렌더해 전부 시각 확인했다. 전처리 인용과 정답 요소의 숫자·단위·부등호·기간·조치 대상·문서/쪽을 비교했다. 모델과 새 패키지는 설치하지 않았다.

검토 범위에서 정답에 쓰인 원문 수치 자체를 바꿀 오류는 발견하지 않았다. 수정은 질문과 필수 채점 요소의 불일치, 겹치는 조건, 구간 끝점의 모호함, 인용 중복 채점 등을 해소하는 것이다. 원문 자체의 모순·차이는 임의로 해결하지 않는다.

## 수정한 문항

| ID | 수정 목적 |
|---|---|
| Q03, Q04 | 여러 경보 분기 중 묻는 CRITICAL 분기를 명시 |
| Q10 | 필수 정답인 안전 판단 한계도 질문에서 요청 |
| Q12 | 필수 정답인 규칙 ID도 질문에서 요청 |
| Q16, Q17, Q18 | 질문하지 않은 설치 모델 확인을 숨은 필수 점수에서 제거 |
| Q19 | 모호한 전류 범위 표현을 원문 항목으로 한정, 끝점 임의 해석 금지 |
| Q21 | 인용 위치를 내용 점수와 근거 점수에서 중복 채점하지 않도록 정리 |
| Q22, Q23, Q24 | 개인 판정 한계·시간 의미·최대 인원 등 채점 요구를 질문에 명시 |
| Q28 | 일반 시간 정의와 개별 관계의 측정값 구별을 질문에 명시 |
| Q29 | 자료 범위와 확인 불가 이유·추가 자료 요구를 명확히 함 |

그대로 통과: Q01, Q02, Q05~Q09, Q11, Q13~Q15, Q20, Q25~Q27, Q30.

## 저장과 검증

- 현재 질문: `docs/benchmark_yewon_v2_20261023/문항목록.md` 및 질문 JSONL.
- 상세 30문항 판정·변경 전후: `evaluation/benchmark_yewon_v2_20261023/원문검토_결과_PRIVATE.md`와 `source_review_PRIVATE.json`.
- 수정된 정답·근거: 같은 평가 폴더의 `정답과_근거_PRIVATE.md`, `answer_key_PRIVATE.json`.
- 이전 질문·정답·manifest·빈 채점표: `before_source_review/`에 보존.
- 14개 실제 변경 ID와 판정 기록 일치, 30개 ID/6·24 분할 유지, 90행 채점표 미채점 상태, 현재 질문·정답 해시 확인.
- 원래 예원 v2 KG·추출 결과 해시 불변. 다른 팀원 통합과 보완 레이어는 사용하지 않았다.

원문에 정보가 없다는 판정은 검토한 7개 정적 문서에만 한정한다. 원문의 직접 사실, 산술·비교 결과, 정보 한계 추론을 구별했다. PDF를 확인한 작성 AI의 재검토이지 독립 검토자나 제조 전문가 승인은 아니다. 전문가가 제조 안전성을 검증했다고 표현하지 않는다.

현재 버전은 `yewon-v2-qa-source-reviewed-r1-20261023`. **다음은 2단계 채점 기준 확정**이다. 이번에는 Vector RAG 구현·6문항 실행·API 호출·Git 커밋/푸시를 수행하지 않았다.
