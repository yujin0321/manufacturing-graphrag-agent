# 팀 공유 묶음 최종 확인

2026-10-28. [전체 점검](e2e_handoff_20261028_verify.md) 이후 ZIP 생성 및 별도 폴더 실행 검증을 완료했다. 최근 정한 4단계의 로컬 구현·검증·공유 묶음 준비는 완료다. Git 푸시나 팀원에게 전송하는 작업은 수행하지 않았다.

| 파일 | 크기 | 파일 수 |
|---|---:|---:|
| imaks_agent_runtime.zip | 3,050,580바이트 (약 2.91MiB) | 54개 + 내부 manifest |
| imaks_gold_demo_ONLY.zip | 23,810바이트 (약 23.25KiB) | 10개 + 내부 manifest |

위 파일과 `bundles.json`은 `kg_build/team_handoff_20261028/`에 있다. 생성 시 ZIP CRC 및 내부 모든 파일의 SHA-256을 확인했다. 일반 ZIP의 명시적 파일 목록에서 정답 시연·kg_seed·ground_truth 파일을 차단했고 현재 환경의 API 키가 파일에 포함되지 않음을 검사했다.

일반 ZIP을 `kg_build/e2e_handoff_20261028/runtime_smoke/`에 새로 풀어 기존 가상환경의 Python으로 검사했다. 자식 프로세스에서 OPENAI_API_KEY를 제거하고 다음을 확인했다.

- 추출된 묶음의 코드로 v2 KG 2,806트리플 로드.
- 문서 인덱스 무결성 확인과 86청크 로드.
- 봉인된 후보 93건 로드.
- MAINT-05 후보의 실제 값 26.9452와 근거 조회.
- 저장된 실패·성공·선택 요청·현재 상태 유보 화면 데이터 4종 로드.

모두 통과했고 종료 코드는 0이다. 기록은 `kg_build/e2e_handoff_20261028/bundle_smoke.json`이다. 이 검사는 같은 컴퓨터의 기존 Python 패키지를 이용했으며, 새 운영체제에서의 패키지 설치나 실제 팀원 계정의 API 권한까지 검증한 것은 아니다. 원본 전체 데이터와 전체 평가 재실행 자료는 포함하지 않았다.

통합 테스트 50개 통과 및 기준선 699개 파일 무변경 결과는 전체 점검 보고서에 있다. 이번 단계에서는 새 유료 API 호출을 하지 않았다. 이전 실제 모델 대표 사례의 한계와 개발 재시험 성격은 유지된다.

팀원에게는 두 ZIP을 **각각 다른 폴더**에 풀고 일반 묶음의 `docs/TEAM_HANDOFF_20261028.md`를 먼저 읽도록 안내한다. 정답 시연 ZIP은 일반 평가 입력에 합치지 않는다. 별도 HTML만 열면 추가 설치·API 없이 정답 제공 시연을 볼 수 있다.
