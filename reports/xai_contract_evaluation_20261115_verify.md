# Agent XAI 검증 평가 보고서 — 2026-11-15

## 결론과 범위

기존 탐지 정책·고정 v2 KG·모델 답변과 점수는 보존했다. 새로 확인한 것은 **규칙 경계와 사후 종료의 설명, 주장–원문 연결, 참조 오류 차단**이다. 추가 유료 API 호출·새 모델 학습·새 임베딩은 0회다. UI는 별도 담당자 범위다.

관계/출처/정책 검사 결과를 이상 탐지 정답 정확도나 새 LLM·Vector RAG·GraphRAG 성능 점수로 해석하면 안 된다. 개발 중 사용한 자료와 의도적으로 만든 오류에 대한 검사이며 미노출 평가가 아니다.

## 1. 규칙 경계와 종료 기록

| 저장 방식 | 사건 | 알람 | 경계 설명 지원 | 사후 종료 검사 일치 |
|---|---:|---:|---:|---:|
| 기본 v3.1 | 17 | 120 | 120 | 120 |
| 유진 v3.2 | 17 | 120 | 120 | 120 |
| 성호 연속 2점 | 55 | 55 | 55 | 55 |
| 성호 연속 2점 + DRIFT | 89 | 89 | 89 | 89 |
| 합계 | 178 | 384 | 384 | 384 |

현재 저장 알람은 모두 규칙 조건 해제 관측까지 있는 사례다. 관측 공백·자료 종료·특징 미계산은 별도 합성 사례로 확인했다. 기본 1회 해제와 성호 2회 확인/1회 비충족 연결 정책을 구분했고 사건 끝값 집계 178건도 일치했다. 방식 간 같은 원시 관측·규칙이 중복되므로 독립 사건 178건의 이상 정답 성능으로 해석하지 않는다.

기울기 감시의 종료는 원래 기울기 신호 구간을 검사한다. 승격 게이트는 기존 검사와 별도로 연결하며 원인·설비 회복을 확정하지 않는다. 사건 묶음·분류 전체와 조치 효과는 범위 밖이다. [집계 원본](../docs/agent_handoff/rule_explanations_audit.json).

## 2. 문서 발췌 참조

고정 문서 검색 행 157개에서 발췌 주장 186개를 생성해 원문 일치와 출처 경로를 확인했다. 청크 텍스트·문서·쪽·부모·행·해시·문자 범위를 대조했다. 실제 모델이 186개를 올바르게 선택해 답했다는 결과가 아니며 조건부 적용·PDF 시각 검증·도메인 의미 전체 판정도 아니다.

통합 Agent는 새 문서 답변에서 발췌 ID 선택→코드 조립→AI 관련성/완전성 검토를 수행한다. 실제 유료 답변 생성은 실행하지 않고 모의 모델과 실제 BM25 검색으로 연결을 확인했다. 기존 자유답변은 재작성·소급 인증하지 않았다.

## 3. 통제 오류 탐지와 정상 대조

| 검사 범주 | 정상 대조 통과/전체 | 오류 차단/주입 |
|---|---:|---:|
| 관측·규칙·원문 근거 | 1/1 | 5/5 |
| 그래프 방향·출처 경로 | 2/2 | 5/5 |
| 사건 주장 선택 | 1/1 | 4/4 |
| 문서 발췌 선택·메타데이터 | 1/1 | 8/8 |
| 종료·공백·자료 끝 | 3/3 | 2/2 |
| 합계 | 8/8 | 24/24 |

총 32개 통제 사례를 모두 통과했다. 오류 미탐지 0/24, 정상 대조의 잘못된 차단 0/8이다. 작은 개발용 구성 사례의 결과이므로 현장에서 오류를 모두 차단한다는 보증이 아니다. 숫자·단위 변조, 알람/원문 누락, 역방향 간선, 규칙/출처 간선 누락, 재해시한 잘못된 쪽, 없는·중복·다른 검색 ID, 추가 실행 단정, 원문/파일 해시/부모 변조, 잘못된 종료·정상 확인 시각을 포함한다. 예외 발생 자체를 탐지 성공으로 계산하지 않으며 예상 밖 예외는 실험 실패로 중단한다.

[사례별 결과·보존 해시 JSON](../docs/agent_handoff/xai_contract_evaluation.json). 원문 발췌나 API 원본을 추가 공개하지 않는 집계다.

## 4. 보존과 남은 한계

- 기존 Agent·주장·경로·창 연산·도구·인계·API를 포함한 무료 회귀 검사 **132개 통과**. 모의 모델과 로컬 HTTP를 사용했으며 새 실제 모델 호출은 없다.
- 실제 읽기 전용 서버에서 기본 사건·성호 후보·문서 검색 3개 저장 사례의 새 API 응답과 원 답변 보존을 확인했다. [로컬 HTTP 점검 집계](../docs/agent_handoff/xai_extensions_server_audit.json).
- 기존 실제 모델 실행 4개의 `answer.json` 해시가 실험 전후 일치했다. 원래 답변·입력·점수는 변경하지 않았다.
- 경계의 변경 가정은 다른 조건을 고정한 수학적 비교다. 물리적 최소 개입이나 조치 효과가 아니다.
- 사후 종료는 미래 관측을 사용하므로 발동 당시 근거와 구분한다. 관측 공백이나 자료 끝을 정상 회복으로 채우지 않는다.
- 문서 발췌에 모든 예외·조건이 충분히 포함됐는지, 질문에 관련 있는지, 답변이 완전한지는 별도 AI 검토 영역이며 새 실제 성능은 미측정이다.
- 표 행/쪽/파일 해시는 고정 추출 자료의 참조 검사다. 원본 PDF 열·문자 배치를 시각 확인한 것은 아니다.
- 기존 3종 비교 점수를 새 기능의 점수로 갱신하지 않았다. 새 독립 평가나 추가 유료 실험 없이 개발 검증 범위만 보고한다.
