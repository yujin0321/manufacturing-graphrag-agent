# GraphRAG 검색 개선 v2 — 실제 답변 비교 결과

2026-10-24. 4번(개선판 별도 답변 생성·비교)을 완료했다. 예원 v2 KG는 유지하고 검색 방식만 별도 개선한 시스템이다. 이번 결과는 이미 사용한 문항의 **개발 재시험**이며 미노출 평가가 아니다.

## 결과

고정된 `docs/benchmark_yewon_v2_20261023/채점기준_확정_v1.md`로 AI가 답변을 원문과 직접 대조했다. 문항별 내용 3점, 근거 1점, 충실성 1점이다. 기준·정답·배점은 변경하지 않았다.

dev 6문항은 별도 집계했다. 기존 GraphRAG 23.5/30·4/6 완전 정답에서 v2 **30/30·6/6**으로 개선됐다. eval과 합쳐 대표 점수를 만들지 않는다.

Q29는 검색 발췌에 SOP-004가 없어서 '실제 제공된 발췌에는 SOP 3개'라는 부연을 했다. 저장 컨텍스트에 SOP-001/002/003만 있음을 확인했다. 전체 원본이 3개라고 주장한 것은 아니므로 충실성 감점은 하지 않았지만, 전체 코퍼스(4개 SOP)와 검색 발췌의 범위를 혼동시킬 수 있는 표현이다. 만점은 문장 품질까지 완벽하다는 의미가 아니다.

## 실행 방식과 검증

- 3번에 저장·해시 검증한 `kg_build/graphrag_v2_retrieval_20261024/`의 30개 컨텍스트를 그대로 사용했다. 근거 내용·순서를 생성 시 다시 최적화하지 않았다.
- 모델 요청/반환 ID 모두 `gpt-6.1-sol`. 기존 공통 지침과 생성 설정을 유지했다. 문항마다 독립 요청, `store=false`, `max_completion_tokens=4096`, temperature/seed 미지정이다.
- dev 6개를 생성·점검한 다음 설정 변경 없이 eval 24개를 생성했다. 실행 중 정답·점수에 따라 재생성하거나 좋은 답변을 선택하지 않았다.
- 모든 실제 API 요청은 공통 지침과 질문·고정 검색 컨텍스트만 포함하는지 대조했다. 정답표나 이전 채점 결과는 생성 요청에 넣지 않았다. 이것이 과거 개발 과정의 정답 노출 이력을 제거한다는 뜻은 아니다.
- 답변 30개 정상 완료, 출력 중단/거절 없음. 요청·응답 원본과 답변 해시를 보존했다. 신규 임베딩 0회.
- 최초 제한 환경에서 연결 실패 1회가 있었고 별도 무인증 연결 검사에서 DNS 오류(gaierror 11001)를 확인했다. 실패 기록을 보존한 뒤 네트워크 권한으로 복구했다. 자동 재시도와 완료 답변 재생성은 없었다.
- 기준선 ZIP 699개 파일 검증 통과, 보존 대상 작업 파일 차이 0. KG/기존 점수/원문/평가 기준을 덮어쓰지 않았다. Git 푸시는 하지 않았다.

API 필드 확인에는 [OpenAI 공식 Chat Completions 문서](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)를 참고했다. 현재 모델의 공개 가격을 별도로 검증하지 않았으므로 달러 비용은 추정하지 않는다.

## 해석 한계

1. 이미 본 24문항과 그 실패 양상을 사용한 개발 개선이다. 미노출 일반화 성능 또는 데이터 누수 없는 독립 평가로 발표하지 않는다.
2. 채점자는 구현·기존 결과를 알고 있는 AI다. 시스템 이름을 가려도 실질적 블라인드가 되지 않으므로 **AI 단독·비블라인드·비독립 채점**으로 명시한다. 독립 인간 검토는 하지 않았다.
3. 이번 전후 비교에는 후보 수 증가, ID 처리, 문서별 근거 확보, 순위 결합, 출처 탐색, 그래프 카드 등이 함께 바뀌었다. 생성도 단회 표본이다. 점수 상승을 순수 그래프 효과나 통계적 우월성으로 해석하지 않는다.
4. 앞선 B/C 실험은 **검색만** 비교했으며 eval 필수 근거가 34/35→35/35였다. 이번 응답은 3번의 GraphRAG v2 컨텍스트로 생성한 것이며 B/C 답변 비교나 동일 원문 C/D 카드 제거 실험이 아니다. 그 실험들은 수행했다고 주장하지 않는다.
5. 이 점수는 문서 기반 QA의 내용·근거·충실성 점수다. 추출 F1_content 86.19%, 이상탐지율, 신규 인과 발견, 현장 안전 검증과는 별개다.

권장 발표 문구: **“동일한 예원 v2 KG를 유지한 채 검색을 개선한 개발 재시험에서, 기존 24문항 QA 총점이 106.5/120에서 120/120으로 상승했다. AI 단독 채점이며 미노출 성능과 그래프 고유 효과는 별도 검증이 필요하다.”**
